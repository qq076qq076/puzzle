# microorganism 遊戲規劃

## 1. 遊戲概念

`microorganism` 是一個觀察型微生物遊戲。玩家在畫面上的 150×150 格培養區選擇並放置多隻微生物，觀察黑色微生物與綠色條蟲用各自的四格身體持續爬行。兩種菌種可以同時存在多個獨立個體。

第一版不加入得分、敵人、環境值或繁殖，先驗證多個獨立微生物的身體資料與固定時間步進。

## 2. 第一版目標

- 顯示一個邏輯尺寸為 150×150 的方格培養區。
- 玩家先選擇黑色微生物或綠色條蟲，再點擊空白區放置新的個體。
- 每隻微生物初始體積固定為 4 格，且自己的四格互相連通。
- 黑色微生物每 150 毫秒移動一次；綠色條蟲每 250 毫秒移動一次。
- 每次移動新增一個身體鄰近空格，再收回一個原本被身體佔用的格子，因此體積永遠維持 4 格。
- 不同微生物不可重疊；移動時也不能伸入其他微生物佔用的格子。
- 讓玩家可以暫停、繼續與重置，方便觀察單步變化。

## 3. 畫面與操作

### 3.1 畫面

- 遊戲名稱：`microorganism`。
- 主遊戲區：150×150 邏輯格，以 Canvas 顯示；Canvas 可隨螢幕縮放，但邏輯座標永遠維持 0～149。
- 背景：米白色培養皿，顯示細緻網格與較淡的區段線，避免 22,500 格造成視覺噪音。
- 黑色微生物：純黑色，佔用格以圓角方塊與微小連接感呈現。
- 綠色條蟲：綠色四格連續條狀身體，以深綠色標記頭部；移動時保留短暫的方向痕跡。
- 資訊面板：顯示目前選項、狀態、體積、移動次數、更新間隔與目前座標。

### 3.2 操作

- 選擇微生物：選取黑色微生物或綠色條蟲，之後的點擊會放置所選菌種。
- 點擊空白區：在點擊位置附近放置一隻新的四格微生物；可重複操作以放置多隻。
- 點擊會與既有身體重疊的位置：不放置新個體並提示玩家改點空白區。
- 「暫停／繼續」：停止或恢復模擬時鐘，所有個體一起暫停或繼續；各菌種仍依自己的移動間隔執行。
- 「重置」：清除微生物與移動紀錄，回到等待放置狀態。
- 鍵盤 `Space`：切換暫停／繼續；`R`：重置。

## 4. 微生物資料設計

### 4.1 第一種微生物

| 欄位 | 設定 |
| --- | --- |
| 名稱 | 黑色微生物 |
| 識別碼 | `black-microbe` |
| 顏色 | `#111111` |
| 初始體積 | 4 格 |
| 移動間隔 | 150 毫秒 |
| 鄰近定義 | 上、下、左、右四方向 |
| 移動方式 | 隨機延伸一格，再隨機收回一格 |
| 邊界行為 | 只從培養區內的合法候選格選擇；沒有候選格時保持原狀 |

每隻微生物的身體以 `Set<cellIndex>` 保存，全部個體放在 `microbes` 陣列。`cellIndex = y * 150 + x`，因此不需要為 22,500 格建立大量 DOM 元素，只在 Canvas 上渲染。

### 4.2 黑色微生物初始四格形狀

玩家點擊位置會先轉換為邏輯座標 `(x, y)`，再嘗試放置 T 形：

```text
    (x, y-1)
(x-1,y) (x,y) (x+1,y)
```

選擇 T 形是因為新生長格可以同時鄰接兩個身體格，收回其中一格後仍能維持四格身體連通；若使用實心 2×2 方形，依目前的「相鄰新增／相鄰收回」規則會沒有可行移動。

如果點擊位置太靠近邊界，T 形會平移到最近的合法位置；若仍無法完整放入，則不放置並提示玩家點擊更靠近中央的位置。

### 4.3 綠色條蟲初始形狀與頭部

綠色條蟲使用四格水平連續條狀身體，左側為尾端、右側為頭部：

```text
(x-3,y) — (x-2,y) — (x-1,y) — (x,y) 頭
```

- 顏色：身體 `#58C96D`，頭部標記 `#218D43`。
- 體積固定為 4 格，`bodyOrder` 由頭到尾保存四格順序，另外保存 `head` 索引。
- 放置時若靠近邊界，整條身體會平移到最近的合法位置。

## 5. 黑色微生物 150 毫秒移動規則

### 5.1 候選延伸格

每次計時器觸發時：

1. 讀取目前身體四格。
2. 取得每一格的上、下、左、右鄰近格。
3. 排除超出 0～149 邊界的格子、目前自己已佔用的格子，以及其他微生物已佔用的格子。
4. 將剩餘格子去重，形成「所有身體佔用格的鄰近空格」清單。
5. 逐一檢查每個候選格，排除「加入後找不到任何安全收回格」的候選。
6. 使用等機率亂數從剩餘候選中選出一格不會造成身體斷裂的 `newCell`。

### 5.2 收回原本佔用格

為了讓身體持續保持一整塊，新增格選定後，從「與 `newCell` 四方向相鄰的原本身體格」中等機率選出一格 `oldCell` 收回：

1. 先將選定的 `newCell` 加入身體與佔用索引，完成延伸移動。
2. 找出目前身體中與 `newCell` 相鄰、且移除後仍能保持連通的 `oldCell`。
3. 從安全的 `oldCell` 清單中等機率隨機選出一格收回。
4. 移除 `oldCell`，讓身體體積回到 4 格。
5. 記錄移動次數、移動前後座標與方向，刷新畫面。

這個規則代表每隻微生物會先從自己的身體邊緣長出一格，再把接近新生長點且不會造成斷裂的舊格收回；新增方向由整個身體的鄰近空格共同決定，而不是固定朝單一方向前進。移動順序採逐隻處理，後續個體會讀取前一隻完成延伸與收回後的佔用狀態。

### 5.3 黑色微生物無法移動時

- 如果所有身體鄰近格都在邊界外或不存在合法空格，本次計時不改變身體。
- 本次仍算一次更新嘗試，資訊面板顯示「等待可用鄰近格」。
- 在一般開放培養區中不會遇到此情況，保留此規則是為了日後加入障礙物或其他微生物。

## 6. 綠色條蟲 250 毫秒移動規則

每 250 毫秒只讀取綠色條蟲目前的頭部位置，從頭部的上、下、左、右四個鄰近格中隨機選擇下一格：

1. 排除超出培養區邊界、目前身體已佔用，以及其他微生物已佔用的格子。
2. 若沒有合法候選格，這次更新保持原狀。
3. 選出 `newHead` 後，將新頭部接到 `bodyOrder` 前方。
4. 收回 `bodyOrder` 最後一格作為尾端，體積維持 4 格。
5. 因為新頭部一定鄰接舊頭部，而舊頭部會成為第二節，所以身體仍維持連續條狀。

綠色條蟲不會從身體其他部位尋找方向，也不會任意移除身體中段；移動方向完全由頭部相鄰格決定。

## 7. 狀態與渲染

### 6.1 遊戲狀態

```js
{
  gridSize: 150,
  baseTickMs: 50,
  selectedTypeId: "black",
  paused: false,
  microbes: [
    {
      id: 1,
      typeId: "black",
      color: "#111111",
      cells: Set<number>,
      steps: 0,
      placed: true,
      moveAccumulator: 0,
      bodyOrder: null,
      head: null
    }
  ],
  totalMoves: 0
}
```

狀態更新只修改微生物的 `cells` 與統計資料；畫面由同一份狀態重繪，避免視覺位置與邏輯格不同步。

### 6.2 Canvas 渲染

- Canvas 使用固定邏輯尺寸 150×150，再依 CSS 顯示尺寸計算每格像素大小。
- 背景以低透明度繪製網格；每 10 格與每 50 格增加區段線。
- 黑色與綠色微生物每格繪製成留有小間隙的圓角方塊；綠色條蟲的頭部再加深色標記。
- 移動後保留最近 8 次移動軌跡，軌跡透明度由新到舊遞減。
- 游標移入時顯示目前邏輯座標，方便確認 150×150 座標系。

### 6.3 更新與擴充架構

- 模擬更新與畫面渲染分離：以 50ms 基礎時鐘驅動各菌種的 150ms／250ms 間隔，畫面使用 `requestAnimationFrame` 渲染，並在模擬更新之間補足爬行動畫。
- 靜態網格先繪製到快取 Canvas；每幀只合成網格快取、軌跡、微生物與游標，不重畫 22,500 格的背景線。
- 使用 `occupancy: Map<cellIndex, microbeId>` 維護佔用索引，放置與移動時增量更新，不再為每隻微生物反覆掃描所有個體建立佔用集合。
- 微生物種類集中在 `MICROBE_TYPES` 設定，移動演算法集中在 `MOVEMENT_STRATEGIES`；新增顏色、體積或移動模式時，不需改動主迴圈與渲染流程。
- 每隻微生物保存自己的 `cells`、移動次數、連通狀態與視覺移動狀態，個體之間只透過佔用索引互相避讓。

## 8. 驗收標準

- 規格上明確顯示 150×150 格，而非以 15×15 或其他縮小邏輯格代替。
- 每次點擊空白位置都能新增所選的黑色或綠色微生物，且每隻正好佔用 4 格。
- 黑色微生物每 150 毫秒最多完成一次延伸／收回；綠色條蟲每 250 毫秒最多完成一次頭部移動；每次完成後體積仍為 4 格。
- 新增格必須是移動前身體任一格的四方向鄰近空格。
- 收回格必須是原本身體中、且與新增格四方向相鄰的格子。
- 每次移動後，四格身體必須通過四方向連通性檢查，不得分裂成兩個以上區塊。
- 綠色條蟲每次只能從頭部的四方向鄰近空格選擇新頭部，並收回尾端。
- 不同個體不可重疊，且移動後仍各自保持獨立。
- 暫停後所有身體不再變化，繼續後恢復各菌種的 150／250 毫秒節奏。
- 重置後畫面回到空白培養區，所有統計歸零。
- 遊戲在桌面與窄螢幕都能操作，Canvas 不應造成頁面水平溢出。

## 9. 後續擴充方向

- 新增不同顏色、不同體積與不同移動偏好的微生物。
- 加入障礙格、培養液環境與微生物互相碰撞。
- 讓玩家設定移動間隔，或以慢動作逐步檢視每次延伸／收回。
- 將移動規則抽成可配置的行為模組，方便擴充群體模擬。
