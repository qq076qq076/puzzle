# microorganism 遊戲規劃

## 1. 遊戲概念

`microorganism` 是一個觀察型微生物遊戲。玩家在畫面上的 150×150 格培養區選擇並放置多隻微生物，觀察黑色微生物、綠色條蟲、紅色微生物、淺藍水母與紫色微生物用各自的身體規則持續爬行或游動。五種菌種可以同時存在多個獨立個體，紅色微生物能追向並吞噬其他生物，紫色微生物則是唯一能吞噬紅色微生物的菌種；兩隻不同黑色微生物碰觸時也可能產生新的黑色微生物。

目前版本不加入得分、環境值或關卡，先驗證多個獨立微生物的身體資料、碰撞互動與固定時間步進。

## 2. 第一版目標

- 顯示一個邏輯尺寸為 150×150 的方格培養區。
- 玩家先選擇黑色微生物、綠色條蟲、紅色微生物、淺藍水母或紫色微生物，再點擊空白區放置新的個體。
- 黑色微生物與綠色條蟲初始體積為 4 格；紅色微生物初始體積為 5 格；淺藍水母張開姿勢初始為 7 格，且初始身體互相連通。
- 黑色微生物每 150 毫秒移動一次；綠色條蟲每 250 毫秒移動一次。
- 紅色微生物每 250 毫秒切換一次動作階段：延伸兩格後停留 250 毫秒，接著收回兩格，再停留 250 毫秒才開始下一次延伸；每吞噬兩格其他生物，自己的身體增加一格。
- 綠色條蟲每次觸發移動時有 1/3 機率休息，不改變頭部與身體。
- 淺藍水母張開到最大後停留 500 毫秒，再先決定米字八方向並收縮揮動前進兩格；移動完成後的收縮姿勢也停留 500 毫秒，再張開到最大。
- 淺藍水母若被紅色微生物吞噬而損失格子，停止移動 3 秒，接著在原本姿勢與方向恢復 7 格張開狀態；恢復期間紅色微生物不能繼續吞噬它。
- 紫色微生物初始為五格十字核心，每次有 25% 機率不移動；移動會朝核心的上、下、左、右之一前進一格並張開，張開停留 100 毫秒、收回耗時 500 毫秒、收回後停留 250 毫秒。
- 紫色微生物偏好移向沒有生物的區域；它是唯一能吞噬紅色微生物的菌種，吞到一格紅色後會追向其他紅色格並逐格吞噬，當次吞噬動作的 100／500／250 毫秒節拍減半。
- 兩隻不同黑色微生物四方向碰觸時有 50% 機率產生一隻新的黑色微生物；成功產出後全域冷卻 3 秒。
- 黑色、綠色、淺藍水母與紫色微生物不能重疊；紅色微生物可以覆蓋黑色、綠色或淺藍水母格，並在移動完成時吞噬那些格子；紅色不會吞噬紅色或紫色，其他菌種也不能吞噬紅色。
- 讓玩家可以暫停、繼續與重置，方便觀察單步變化。

## 3. 畫面與操作

### 3.1 畫面

- 遊戲名稱：`microorganism`。
- 主遊戲區：150×150 邏輯格，以 Canvas 顯示；Canvas 可隨螢幕縮放，但邏輯座標永遠維持 0～149。
- 背景：米白色培養皿，顯示細緻網格與較淡的區段線，避免 22,500 格造成視覺噪音。
- 黑色微生物：純黑色，佔用格以圓角方塊與微小連接感呈現。
- 綠色條蟲：綠色四格連續條狀身體，以深綠色標記頭部；移動時保留短暫的方向痕跡。
- 紅色微生物：紅色五格連通身體；延伸時以兩段軌跡呈現，延伸與收回之間各停留 250 毫秒，吞噬其他生物後保留成長的身體格。
- 淺藍水母：淺藍色身體、深藍色頭部；張開時為水平傘狀七格，收縮時為六格縱向揮動姿勢。移動方向可為上、下、左、右與四個斜角。
- 紫色微生物：紫色身體與深紫色核心；一般狀態為五格十字，移動後依方向旋轉成附圖的十三格張開狀態，再收回至五格。
- 資訊面板：顯示目前選項、狀態、體積、移動次數、更新間隔與目前座標。

### 3.2 操作

- 選擇微生物：選取黑色微生物、綠色條蟲、紅色微生物、淺藍水母或紫色微生物，之後的點擊會放置所選菌種。
- 點擊空白區：在點擊位置附近放置所選形狀的微生物；可重複操作以放置多隻。
- 點擊會與既有身體重疊的位置：不放置新個體並提示玩家改點空白區。
- 「暫停／繼續」：停止或恢復模擬時鐘，所有個體一起暫停或繼續；各菌種仍依自己的移動間隔執行。
- 「重置」：清除微生物與移動紀錄，回到等待放置狀態。
- 鍵盤 `Space`：切換暫停／繼續；`R`：重置。

## 4. 微生物資料設計

### 4.1 第一種微生物

| 欄位 | 設定 |
| --- | --- |
| 名稱 | 黑色微生物 |
| 識別碼 | `black-microbe` |
| 顏色 | `#111111` |
| 初始體積 | 4 格 |
| 移動間隔 | 150 毫秒 |
| 鄰近定義 | 上、下、左、右四方向 |
| 移動方式 | 隨機延伸一格，再隨機收回一格 |
| 邊界行為 | 只從培養區內的合法候選格選擇；沒有候選格時保持原狀 |
| 碰觸繁殖 | 與不同黑色微生物四方向相鄰時，50% 機率產生新黑色微生物 |
| 產出冷卻 | 成功產出後 3 秒內不再產出 |

每隻微生物的身體以 `Set<cellIndex>` 保存，全部個體放在 `microbes` 陣列。`cellIndex = y * 150 + x`，因此不需要為 22,500 格建立大量 DOM 元素，只在 Canvas 上渲染。

### 4.2 黑色微生物初始四格形狀

玩家點擊位置會先轉換為邏輯座標 `(x, y)`，再嘗試放置 T 形：

```text
    (x, y-1)
(x-1,y) (x,y) (x+1,y)
```

選擇 T 形讓初始身體具有清楚的中心與四個方向延伸面；收回格只要求移除後維持四方向連通，不要求必須與新增格相鄰，因此微生物可以逐步離開初始區域。

如果點擊位置太靠近邊界，T 形會平移到最近的合法位置；若仍無法完整放入，則不放置並提示玩家點擊更靠近中央的位置。

### 4.3 綠色條蟲初始形狀與頭部

綠色條蟲使用四格水平連續條狀身體，左側為尾端、右側為頭部：

```text
(x-3,y) — (x-2,y) — (x-1,y) — (x,y) 頭
```

- 顏色：身體 `#58C96D`，頭部標記 `#218D43`。
- 體積固定為 4 格，`bodyOrder` 由頭到尾保存四格順序，另外保存 `head` 索引。
- 放置時若靠近邊界，整條身體會平移到最近的合法位置。

### 4.4 紅色微生物初始形狀與吞噬資料

紅色微生物使用五格十字形身體：

```text
    (x,y-1)
(x-1,y) (x,y) (x+1,y)
    (x,y+1)
```

| 欄位 | 設定 |
| --- | --- |
| 名稱 | 紅色微生物 |
| 識別碼 | `red` |
| 顏色 | `#d94a42` |
| 初始體積 | 5 格 |
| 移動間隔 | 250 毫秒（本版未另指定速度，先沿用綠色條蟲的間隔） |
| 移動方式 | 隨機選一格身體，沿一個方向連續延伸兩格，停留 250 毫秒後收回其他原本身體格，再停留 250 毫秒 |
| 特殊能力 | 覆蓋其他微生物格時吞噬；累計每兩格吞噬量讓自己增加一格身體 |

紅色微生物額外保存 `bodySize`、`consumedCells`、`growthLevel`、`predatoryPhase` 與 `pendingPredatoryMove`。實際體積以 `cells.size` 為準；當吞噬獎勵讓身體成長時，本次收回數由兩格減為一格，讓「吞噬兩格增加一格身體」能在同一次收回後立即反映。

### 4.5 淺藍水母姿勢、頭部與受損狀態

淺藍水母以固定的局部座標保存姿勢，局部座標的 `y` 負方向就是頭部方向。初始與張開蓄力姿勢使用七格：

```text
        (0,-1) 頭
(-2,0) (-1,0) (0,0) (1,0) (2,0)
        (0,1)
```

揮動後使用六格收縮姿勢；中央仍是同一個姿勢錨點，最上方的格子是頭部：

```text
        (0,-2) 頭
        (0,-1)
    (-1,0) (0,0) (1,0)
        (0,1)
```

| 欄位 | 設定 |
| --- | --- |
| 名稱 | 淺藍水母 |
| 識別碼 | `light-blue` |
| 顏色 | 身體 `#8ad9ed`，頭部 `#2c9fbd` |
| 張開體積 | 7 格 |
| 收縮體積 | 6 格 |
| 移動間隔 | 500 毫秒（每個姿勢階段） |
| 姿勢停留 | 張開到最大 500 毫秒；移動完成後 500 毫秒 |
| 方向 | 米字八方向：上、右上、右、右下、下、左下、左、左上 |
| 移動方式 | 張開蓄力後收縮揮動，沿選定方向前進兩格，再於下一階段張開 |
| 撞紅反應 | 撞到紅色微生物時，沿反方向立即反彈四格；若反彈路徑也被佔用則保持原位 |
| 受損恢復 | 被紅色吞噬一格以上後停止 3 秒，恢復受損前的錨點、方向與七格張開姿勢 |

淺藍水母的對角姿勢以八方向連通判斷身體完整，黑色、綠色與紅色仍使用四方向連通；因此水母可以斜向游動而不會被錯誤判定為斷裂。

### 4.6 紫色微生物核心、張開姿勢與吞噬資料

紫色微生物的核心是局部座標 `(0,0)`，一般狀態為五格十字：

```text
    (0,-1)
(-1,0) (0,0) (1,0)
    (0,1)
```

附圖右側的下一步狀態以「向上」作為局部方向，核心仍在中央，張開姿勢使用十三格：

```text
        (0,-2)
    (-1,-1) (0,-1) (1,-1)
(-2,0) (-1,0) (0,0) (1,0) (2,0)
    (-1,1) (0,1) (1,1)
        (0,2)
```

向上、向下、向左移動時，張開姿勢會依選定的四方向旋轉；核心本身只會沿上、下、左、右移動一格。紫色微生物保存 `purpleCore`、`purpleDirection`、`purplePhase`、`purplePhaseStartedAt`、`purpleHuntingRed` 與 `purpleFastAction`，讓方向、階段計時與追紅狀態彼此分離。

| 欄位 | 設定 |
| --- | --- |
| 名稱 | 紫色微生物 |
| 識別碼 | `purple` |
| 顏色 | 身體 `#9b59d6`，核心 `#5b2d86` |
| 一般體積 | 5 格 |
| 張開體積 | 13 格 |
| 可選方向 | 上、下、左、右 |
| 不移動機率 | 25% |
| 張開停留 | 100 毫秒 |
| 收回耗時 | 500 毫秒 |
| 收回後停留 | 250 毫秒 |
| 空間偏好 | 候選張開姿勢中，空白格越多的方向權重越高 |
| 特殊能力 | 唯一可以吞噬紅色微生物；吞噬後鎖定其他紅色格並逐格追蹤 |
| 吞噬節拍 | 當次吞噬動作的 100／500／250 毫秒全部減半 |

## 5. 黑色微生物 150 毫秒移動規則

### 5.1 候選延伸格

每次計時器觸發時：

1. 讀取目前身體四格。
2. 取得每一格的上、下、左、右鄰近格。
3. 排除超出 0～149 邊界的格子、目前自己已佔用的格子，以及其他微生物已佔用的格子。
4. 將剩餘格子去重，形成「所有身體佔用格的鄰近空格」清單。
5. 逐一檢查每個候選格，排除「加入後找不到任何安全收回格」的候選。
6. 使用等機率亂數從剩餘候選中選出一格不會造成身體斷裂的 `newCell`。

### 5.2 收回原本佔用格

為了讓身體持續保持一整塊，新增格選定後，從「所有原本身體格中移除後仍能保持連通的格子」中隨機選出一格 `oldCell` 收回：

1. 先將選定的 `newCell` 加入身體與佔用索引，完成延伸移動。
2. 找出目前身體中、移除後仍能保持連通的 `oldCell`（不要求與 `newCell` 相鄰）。
3. 從安全的 `oldCell` 清單中等機率隨機選出一格收回。
4. 移除 `oldCell`，讓身體體積回到 4 格。
5. 記錄移動次數、移動前後座標與方向，刷新畫面。

這個規則代表每隻微生物會先從自己的身體邊緣長出一格，再把任一不會造成斷裂的舊格收回；新增方向由整個身體的鄰近空格共同決定，而不是固定朝單一方向前進，因此能在棋盤上持續隨機漫遊。移動順序採逐隻處理，後續個體會讀取前一隻完成延伸與收回後的佔用狀態。

### 5.3 黑色微生物無法移動時

- 如果所有身體鄰近格都在邊界外或不存在合法空格，本次計時不改變身體。
- 本次仍算一次更新嘗試，資訊面板顯示「等待可用鄰近格」。
- 在一般開放培養區中不會遇到此情況，保留此規則是為了日後加入障礙物或其他微生物。

### 5.4 黑色微生物碰觸繁殖

兩隻不同黑色微生物的身體格只要出現上、下、左、右相鄰，就視為碰觸：

1. 每一對黑色微生物在剛形成碰觸時擲一次 50% 機率。
2. 成功時，在碰觸附近尋找不重疊的合法 T 形四格位置，產生一隻新的黑色微生物。
3. 成功產出後設定全域 3 秒冷卻；冷卻期間新碰觸不會再次產出。
4. 同一對黑色微生物持續相鄰時不會每個更新重複擲骰；分開後再次碰觸才算新的碰觸事件。
5. 若碰觸附近沒有完整空間，這次不產出，也不消耗冷卻時間。

## 6. 綠色條蟲 250 毫秒移動規則

每 250 毫秒只讀取綠色條蟲目前的頭部位置，從頭部的上、下、左、右四個鄰近格中隨機選擇下一格：

1. 先以 1/3 機率休息；休息時不選方向、不收回尾端，這次觸發直接結束。
2. 未休息時，排除超出培養區邊界、目前身體已佔用，以及其他微生物已佔用的格子。
3. 若沒有合法候選格，這次更新保持原狀。
4. 選出 `newHead` 後，將新頭部接到 `bodyOrder` 前方。
5. 收回 `bodyOrder` 最後一格作為尾端，體積維持 4 格。
6. 因為新頭部一定鄰接舊頭部，而舊頭部會成為第二節，所以身體仍維持連續條狀。

綠色條蟲不會從身體其他部位尋找方向，也不會任意移除身體中段；移動方向完全由頭部相鄰格決定。

## 7. 紅色微生物 250 毫秒階段移動與吞噬規則

### 7.1 選擇延伸起點與方向

紅色微生物以 250 毫秒為一個階段節拍，依序執行「延伸 → 等待 → 收回 → 等待」：

1. 從目前所有身體格中選出一格 `origin`，再嘗試四個方向。
2. 由 `origin` 沿同一方向取得連續兩格 `firstCell`、`secondCell`；超出邊界或碰到自己身體的候選排除。
3. 其他微生物佔用的格子不是阻擋物，而是可以被覆蓋的吞噬目標。
4. 以最近的可吞噬微生物為主要目標，若沒有黑色或綠色目標才以其他紅色微生物為目標；比較兩格路徑前後的距離，能縮短距離的方向大幅提高權重，因此紅色微生物會趨向其他微生物但仍保留少量隨機性。

如果培養區內沒有其他生物，所有合法延伸方向恢復等機率。

### 7.2 延伸、收回與維持連通

選定候選後，先把兩格路徑加入紅色微生物，進入延伸等待階段，再於下一個 250 毫秒階段收回原本身體格：

1. `ready` 階段選定起點與方向，加入連續兩格，並進入 `extended` 階段。
2. `extended` 階段固定停留 250 毫秒，兩格新路徑保持佔用，不提前收回。
3. 下一個階段收回預先選定的原本身體格；一般情況收回兩格，且收回後紅色身體必須維持四方向連通。
4. 若本次累計吞噬量跨過兩格門檻，取得一格成長獎勵，本次只收回一格，讓身體總量增加一格。
5. 收回完成後回到 `ready`，再停留 250 毫秒，下一個階段才允許再次延伸。
6. 被選為收回的格子只能來自移動前的原本身體，不會收回剛延伸的兩格。
7. 若某個延伸方向找不到可安全收回的組合，該方向排除，再從其他候選中隨機選擇；若完全沒有合法候選，本次保持原狀。

### 7.3 吞噬其他微生物

延伸階段覆蓋其他微生物格時立即吞噬；收回階段仍依照已保存的待收回清單執行：

1. 從被覆蓋的微生物 `cells` 與佔用索引移除該格。
2. 將該格改由紅色微生物佔用，視為完成吞噬；如果目標剩餘 0 格，就從個體清單移除。
3. 每吞噬兩格其他生物，紅色微生物的 `growthLevel` 增加 1，身體實際體積增加 1 格。
4. 被部分吞噬的條蟲會同步清理 `bodyOrder` 與 `head`，避免後續移動讀取已不存在的格子。

紅色微生物的延伸候選會排除其他紅色微生物佔用的格子，因此紅色不會吞噬紅色，也不會覆蓋紅色身體。

吞噬完成後，培養區不會留下重疊佔用；同一格最後只屬於紅色微生物。

## 8. 淺藍水母 500 毫秒游動與碰撞規則

淺藍水母使用兩個動作階段循環，初始處於張開蓄力姿勢；每個階段維持 500 毫秒：

1. `expanded` 階段先從合法的米字八方向隨機決定並旋轉到下一個前進方向；此階段只調整朝向，不平移錨點。
2. 下一次階段更新時，收縮姿勢沿已預備好的方向前進兩格，切換到 `contracted`；收縮期間不再重新抽方向。
3. `contracted` 階段在移動完成後停留 500 毫秒，下一次階段更新時才張開並重新預備下一個方向。
4. 新姿勢若與紅色微生物重疊，視為撞擊，不覆蓋紅色格，改以目前方向的反方向往回彈四格。
5. 新姿勢若與黑色、綠色、紫色或正在恢復的水母重疊，該方向或該次張開不執行，等待下一次觸發。
6. 八個方向的合法候選等機率抽選，邊界與其他菌種只會排除無法放入的候選。
7. 水母被紅色微生物吞掉身體格時，保存受損前的錨點與方向，進入 `recovery`；3 秒內不移動且不可再次被紅色吞噬，空間允許時恢復原本七格張開姿勢。

## 9. 紫色微生物階段移動與追紅規則

紫色微生物以一般五格狀態作為每次移動的起點，移動核心一格後切換為張開狀態：

1. 在 `ready` 階段先擲 25% 不移動機率；不移動時進入 250 毫秒停留，之後再重新選方向。
2. 未休息時，從核心的上、下、左、右四個方向建立候選，核心沿選定方向移動一格，並以該方向旋轉十三格張開姿勢。
3. 候選會排除超出邊界或與黑色、綠色、淺藍水母、其他紫色微生物重疊的方向；空白格數越多，抽中的權重越高。
4. 張開完成後停留 100 毫秒，進入 `retracting`；收回階段耗時 500 毫秒，結束後回到五格一般狀態。
5. 收回完成後停留 250 毫秒，接著才允許下一次核心移動。
6. 如果候選張開姿勢碰到一格紅色微生物，紫色微生物會先吞掉那一格，再進入張開階段；同一次張開姿勢最多吞一格紅色，避免一次跨越多格吞噬。

吞噬到紅色後，紫色微生物設定 `purpleHuntingRed = true`，下一次選方向時以最近的其他紅色格為追蹤目標，同時仍保留空間偏好的次要權重。只要還有紅色格存在，就會持續朝紅色靠近並逐格吞噬；每次實際吞噬紅色的動作，張開 100 毫秒、收回 500 毫秒、收回後停留 250 毫秒全部除以二。其他菌種不能透過 `consumeForeignCell` 吞噬紅色，只有紫色微生物可以通過這條特殊規則。

### 10.2 Canvas 渲染

- Canvas 使用固定邏輯尺寸 150×150，再依 CSS 顯示尺寸計算每格像素大小。
- 背景以低透明度繪製網格；每 10 格與每 50 格增加區段線。
- 黑色、綠色與紫色微生物每格繪製成留有小間隙的圓角方塊；綠色條蟲的頭部與紫色微生物的核心再加深色標記。
- 移動後保留最近 8 次移動軌跡，軌跡透明度由新到舊遞減。
- 游標移入時顯示目前邏輯座標，方便確認 150×150 座標系。

### 10.3 更新與擴充架構

- 模擬更新與畫面渲染分離：以 50ms 基礎時鐘驅動各菌種的 150ms／250ms／500ms 間隔與紫色微生物的階段計時，畫面使用 `requestAnimationFrame` 渲染，並在模擬更新之間補足爬行動畫。
- 靜態網格先繪製到快取 Canvas；每幀只合成網格快取、軌跡、微生物與游標，不重畫 22,500 格的背景線。
- 使用 `occupancy: Map<cellIndex, microbeId>` 維護佔用索引，放置與移動時增量更新，不再為每隻微生物反覆掃描所有個體建立佔用集合。
- 微生物種類集中在 `MICROBE_TYPES` 設定，移動演算法集中在 `MOVEMENT_STRATEGIES`；新增顏色、體積或移動模式時，不需改動主迴圈與渲染流程。
- 每隻微生物保存自己的 `cells`、移動次數、連通狀態與視覺移動狀態，個體之間只透過佔用索引互相避讓。

## 11. 驗收標準

- 規格上明確顯示 150×150 格，而非以 15×15 或其他縮小邏輯格代替。
- 每次點擊空白位置都能新增所選的黑色、綠色、紅色、淺藍水母或紫色微生物；黑色／綠色初始佔用 4 格，紅色初始佔用 5 格，淺藍水母張開時初始佔用 7 格，紫色一般狀態佔用 5 格。
- 黑色微生物每 150 毫秒最多完成一次延伸／收回；綠色條蟲每 250 毫秒完成一次頭部移動；紅色微生物每 250 毫秒切換一次階段，完整延伸／收回循環為 500 毫秒。
- 黑色微生物新增格必須是移動前身體任一格的四方向鄰近空格。
- 黑色與紅色微生物收回格必須來自移動前原本身體，且紅色身體在可行移動後仍保持四方向連通。
- 黑色與紅色每次移動後都必須通過四方向連通性檢查，不得因自身移動分裂成兩個以上區塊。
- 綠色條蟲每次觸發有 1/3 機率休息；未休息時才從頭部的四方向鄰近空格選擇新頭部，並收回尾端。
- 紅色微生物依序延伸兩格、停留 250 毫秒、收回兩格、再停留 250 毫秒；有成長獎勵時，實際體積增加一格。
- 紅色微生物覆蓋其他生物格時會吞噬，累計吞噬兩格後自己的身體增加一格，且最後不留下重疊佔用。
- 紅色微生物不可吞噬或覆蓋其他紅色微生物。
- 淺藍水母張開到最大後停留 500 毫秒，揮動前進兩格後的收縮姿勢再停留 500 毫秒，且沿事先選定的米字八方向移動。
- 淺藍水母撞到紅色微生物時不覆蓋紅色格，會沿反方向反彈四格；反彈路徑受阻時保持安全姿勢。
- 淺藍水母被紅色吞噬造成損失後，至少停留 3 秒，之後恢復受損前方向、錨點與七格張開姿勢。
- 紫色微生物每次移動只沿核心的四方向前進一格，25% 機率不移動；張開停留 100 毫秒、收回耗時 500 毫秒、收回後停留 250 毫秒。
- 紫色微生物偏好空白格較多的方向，且只有它能吞噬紅色；吞噬一格後會追蹤其他紅色並逐格吞噬，該次動作的三段時間減半。
- 不同黑色微生物四方向碰觸時以 50% 機率產出新的黑色微生物，成功產出後 3 秒內不再產出。
- 黑色、綠色、淺藍水母與紫色個體不可重疊；紅色微生物可在移動過程覆蓋其他個體並完成吞噬，但不可吞噬紅色，其他菌種也不可吞噬紅色。
- 暫停後所有身體不再變化，繼續後恢復各菌種的 150／250／500 毫秒節奏。
- 重置後畫面回到空白培養區，所有統計歸零。
- 遊戲在桌面與窄螢幕都能操作，Canvas 不應造成頁面水平溢出。

## 12. 後續擴充方向

- 新增不同顏色、不同體積與不同移動偏好的微生物。
- 加入障礙格、培養液環境與微生物互相碰撞。
- 讓玩家設定移動間隔，或以慢動作逐步檢視每次延伸／收回。
- 將移動規則抽成可配置的行為模組，方便擴充群體模擬。
