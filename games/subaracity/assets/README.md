# SubaraCity 建築圖示來源

本遊戲使用 Summer Engine 的 [City Kit - Commercial Asset Pack](https://www.summerengine.com/asset-store/pack/city-kit-commercial) 中 Building A–F 的透明預覽圖示：

- `building-a.png` 至 `building-f.png`：建築等級 1–6 的城市圖示；Lv.7 以上沿用最高級圖示，避免加入不一致的素材風格。

素材頁標示 City Kit 的素材採用 **CC0（Public Domain）** 授權，可用於商業與非商業專案，不要求署名。圖示保留在本資料夾中，並以不同等級建築使用；原始素材為 Kenney City Kit，由 Summer Engine 整理提供。
