# 快樂水族箱（Happy Aquarium）規格索引

版本：1.1
狀態：可進入實作
平台：桌面與手機瀏覽器
遊戲模式：單人、即時養成、支援離線進度

規格已依用途拆分。實作或調整功能時，請修改擁有該規則的主題文件，避免在多份文件重複定義相同數值。

## 技術基準

- 魚缸世界：Phaser 4.2.1 WebGL，負責 Sprite、動畫、輸入、鏡頭、音效與特效。
- 管理介面：語意化 HTML/CSS DOM，負責 HUD、商店、倉庫、任務、設定、dialog 與 bottom sheet。
- 遊戲規則：不依賴 Phaser／DOM 的純 JavaScript 核心，作為資源、生命週期、交易與離線結算的唯一真相來源。
- 工具鏈：Vite production build、Node.js 內建測試、既有 PuzzleSave／Firebase 共用層。
- 首版不使用 Arcade Physics、Matter.js 或前端 UI 框架；採自訂 steering 與 spatial hash。
