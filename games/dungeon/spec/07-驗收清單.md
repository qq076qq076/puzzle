# 07｜第一階段驗收清單

## 1. 核心流程

- [ ] 可以從入口開始一場新的 Run。
- [ ] Run 會建立並顯示一組種子。
- [ ] 房間進度會顯示為 `1/6` 到 `6/6`。
- [ ] 前 5 間必定是普通房，第 6 間必定是 Boss 房。
- [ ] 玩家死亡後進入失敗畫面，可以重新開始。
- [ ] 魔王死亡後進入勝利畫面，不會誤判為普通房清場。

## 2. 玩家與戰鬥

- [ ] 玩家只能使用近戰主要攻擊。
- [ ] 近戰攻擊有距離、扇形與有效幀，不會整圈無限命中。
- [ ] 攻擊命中有受擊、擊退與音效／視覺回饋。
- [ ] 玩家受傷有短暫無敵，不會被同一幀多次扣血。
- [ ] 閃避是第一階段必要操作，具有約 1.5 格位移、0.18 秒無敵時間與 1.2 秒冷卻。
- [ ] 閃避不能穿牆或穿越不可行走格，且閃避期間不能發動近戰攻擊。
- [ ] 玩家生命歸零時會停止攻擊與移動輸入。

## 3. 房間與生成

- [ ] 每個房間都有至少一組怪物。
- [ ] 怪物未清除前，出口保持封鎖。
- [ ] 清場後才生成房間主要獎勵並解鎖出口。
- [ ] 相同種子可以重現房間模板、怪物組合與獎勵結果。
- [ ] 入口到出口存在可行走路徑。
- [ ] 上一房由右門離開時，下一房玩家從左門外走入，入口門播放關閉動畫後才開始戰鬥。
- [ ] 玩家必須越過開啟出口的門外觸發線才換房，站在房內或門框中央不會提前切換。
- [ ] 怪物不會在玩家出生點旁立即造成傷害。
- [ ] 陷阱不會封死唯一通路。
- [ ] 房間不會因生成點重疊而產生卡死或無限波次。

## 4. 怪物與 Boss

- [ ] 巨鼠、棒棍哥布林、匕首哥布林與鋼鐵蜘蛛具有可辨識行為差異。
- [ ] 匕首哥布林會主動進入攻擊前搖並突進刺擊，不只追蹤或依賴接觸傷害。
- [ ] 每種敵人的攻擊都有前搖或可理解的警示。
- [ ] 怪物與玩家接觸會造成有冷卻的接觸傷害，近戰／衝撞／投射物仍可造成完整攻擊傷害。
- [ ] 鋼鐵蜘蛛的遠距離能力不會讓近戰玩家無法接近。
- [ ] Boss 有三個可辨識階段。
- [ ] Boss 支援怪物的數量有上限。
- [ ] Boss 死亡後不會重新生成支援怪物。

## 5. 獎勵與 Buff

- [ ] 每個房間至少產生一份可取得獎勵。
- [ ] Buff 會顯示名稱、效果與堆疊數。
- [ ] Buff 的數值不會超過最大堆疊造成無限成長。
- [ ] 被動 Buff 取得後立即生效；立即型獎勵不會進入無法使用的背包狀態。
- [ ] 緊急藥瓶可由電腦 `Q` 與手機 `POTION` 使用，成功時扣除 1 瓶並恢復生命；滿血或無庫存時不消耗。
- [ ] 所有戰鬥 Buff 的堆疊都實際進入對應計算，沒有只顯示名稱但效果未套用的項目。
- [ ] 第 1 房不會產生全都無法立即使用的獎勵。
- [ ] 第 6 房會給予通關遺物。

## 6. 素材與介面

- [ ] 奇幻與機械素材使用 nearest-neighbor，沒有模糊放大。
- [ ] 角色腳底定位、陰影方向與攝影機縮放一致。
- [ ] 玩家、怪物與 Boss 使用素材包的 `Shadow.png`，影子貼近腳底，沒有漂浮感。
- [ ] 角色、怪物、影子、陷阱、生成、命中與道具圖示皆來自指定的兩包 CraftPix 素材，runtime 不生成替代像素素材。
- [ ] 奇幻房與機械房不會混用到明顯衝突的地面 Tiles。
- [ ] 電腦版可只使用鍵盤完成一場 Run，不需要滑鼠。
- [ ] 電腦版不會依賴滑鼠移動、按鍵、滾輪或拖曳事件。
- [ ] 手機版啟動後使用橫式畫面；直式畫面會顯示旋轉提示並暫停遊戲。
- [ ] 手機版左側有攻擊與閃避按鈕，右側有虛擬搖桿。
- [ ] 手機版可只使用右側虛擬搖桿移動與面向，左側按鈕完成攻擊與閃避。
- [ ] 行動版可使用觸控完成選擇獎勵、暫停與重新開始。
- [ ] 未把素材 PNG／PSD 直接暴露成可下載的遊戲功能。
