# 04｜獎勵、道具與 Buff

## 1. 房間獎勵規則

- 每個普通房清場後生成一個獎勵台或寶箱。
- 獎勵台提供三個選項，玩家只能選一個；若希望 MVP 更簡單，可先固定生成一個獎勵。
- 第 1～5 房的獎勵以補強當局近戰構築為主。
- 第 6 房魔王獎勵必定包含一個通關遺物，並顯示本次 Run 統計。
- 已達到最大堆疊的 Buff 不應出現在三選一結果中，除非它提供轉化或替代效果。

素材對應：奇幻素材的寶箱用於一般地城房；射擊素材的獎勵台用於機械污染房；傳送門用於房間轉移或 Boss 階段召喚。

## 2. 獎勵類型

| 類型 | 效果 | 出現方式 |
|---|---|---|
| 治療 | 立即恢復 20 生命 | 普通房低機率或選項 |
| 金幣 | 增加 15～35 金幣 | 普通房固定小額、怪物低機率掉落 |
| 武器模組 | 改變近戰攻擊形狀或節奏 | 三選一主要來源 |
| 被動 Buff | 長時間強化玩家 | 三選一主要來源 |
| 一次性道具 | 本房或下一房使用 | 普通房低機率 |
| 通關遺物 | 提供完整 Run 的強化 | 魔王房固定獎勵 |

## 3. Buff 稀有度

| 稀有度 | 顏色建議 | 出現房間 | 設計目的 |
|---|---|---|---|
| 普通 | 灰／綠 | 1～5 | 清楚、立即有效 |
| 稀有 | 藍 | 2～5 | 形成構築方向 |
| 傳奇 | 紫／金 | 4～6 | 明顯改變玩法但不保證勝利 |

## 5. Buff 疊加規則

- 相同 Buff 依最大堆疊累加；超過最大堆疊時轉成 10 金幣或小型治療。
- 固定數值加成先相加，再套用百分比乘區。
- 同一效果的百分比加成採加算，避免多個 Buff 造成數值爆炸。
- 生命上限增加後，當前生命不自動補滿；明確標示「立即恢復」的 Buff 例外。
- Buff 必須在 HUD 顯示圖示、名稱與目前堆疊數；電腦版使用鍵盤焦點查看說明，手機版使用觸控查看說明。
- 第一階段不加入會永久降低玩家能力的詛咒 Buff，先確保獎勵選擇是正向決策。

## 6. 獎勵抽取保護

- 第 1 房至少提供一個普通傷害或治療選項。
- 第 5 房至少提供一個稀有或傳奇選項。
- 連續兩間房不得讓三個選項完全相同。
- 若玩家已滿血，治療仍可出現但權重降低；不能讓整個獎勵畫面只剩無效治療。
- 魔王通關獎勵不受普通房保底規則影響，固定給予通關遺物。
