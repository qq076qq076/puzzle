# 00｜核心玩法與流程

## 1. 玩家體驗目標

玩家應該在「讀懂敵人動作、抓準近戰距離、使用閃避抓反擊窗口、選擇當局 Buff」之間做決策，而不是只靠接觸敵人連續揮砍。每個房間要在 30～90 秒內完成，第一階段完整 Run 目標為 10～20 分鐘。

## 2. 核心循環

```text
進入房間
  ↓
探索並觸發戰鬥
  ↓
近戰擊敗所有怪物
  ↓
出口解鎖、清場停留 2 秒後獎勵出現
  ↓
選擇獎勵或 Buff
  ↓
前往下一個房間
  ↓
第 5 間後挑戰第 6 間魔王房
```

## 3. Run 狀態

| 狀態 | 說明 |
|---|---|
| `hub` | 入口或重新開始畫面；第一階段可簡化成開始按鈕 |
| `room_intro` | 顯示房間編號、房間類型與短暫安全時間 |
| `combat` | 房門鎖定，生成並處理怪物波次 |
| `reward` | 清場完成，顯示獎勵台或寶箱 |
| `transition` | 玩家走到出口或啟動傳送門 |
| `boss` | 第 6 房的魔王戰，使用獨立 Boss 規則 |
| `victory` | 魔王死亡，顯示通關獎勵與重新開始選項 |
| `defeat` | 玩家死亡，顯示本次 Run 統計與重新開始選項 |

## 4. 房間內流程

1. 玩家從入口點出生，入口短暫無敵 1 秒。
2. 玩家進入房間中央或越過觸發線後，門關閉並開始生成怪物。
3. 怪物可以分成 1～3 波；下一波要等上一波全部死亡或離場後才生成。
4. 所有怪物死亡後，門立刻打開；場上危險物停止，保留 2 秒清場喘息時間。
5. 2 秒結束後獎勵框出現，玩家用左／右方向切換三選一獎勵，用攻擊鍵確認取得其中一項。
6. 出口門保持開啟，玩家必須移動到門口並走過門，才進入下一房間；不使用 Enter 直接跳關，也不顯示前往右門的文字提示，開門動畫就是通行導引。

## 5. 第一階段流程

| 房間 | 角色 | 目標時間 | 主要功能 |
|---:|---|---:|---|
| 1 | 普通房 | 30～45 秒 | 教玩家近戰距離與基礎老鼠／哥布林行為 |
| 2 | 普通房 | 40～60 秒 | 加入陷阱與匕首哥布林 |
| 3 | 普通房 | 45～70 秒 | 加入多波敵人與狹窄地形 |
| 4 | 普通房 | 60～80 秒 | 出現機械蜘蛛與機械污染地形 |
| 5 | 普通房 | 60～90 秒 | 精英配置，混合奇幻與機械敵人 |
| 6 | 魔王房 | 90～180 秒 | 魔王三階段戰鬥與通關獎勵 |

## 6. MVP 不包含的內容

- 多人連線。
- 玩家遠距離武器。
- 多個可操作職業；法師與弓箭手先保留給後續版本或 NPC。
- 複雜城鎮、商店與永久天賦樹。
- 無限地層；第一階段只驗證一層六房的完整循環。
