# 01｜玩家與近戰戰鬥

## 1. 玩家定位

第一階段玩家操作「地城騎士」，使用奇幻素材的騎士角色。玩家沒有主要遠距離攻擊，所有攻擊、升級與 Buff 都圍繞近身風險與位置判斷設計。

## 2. 初始數值目標

這些數值是第一階段的平衡起點，實作後依實際素材碰撞尺寸與測試調整。

| 屬性 | 初始值 | 說明 |
|---|---:|---|
| 最大生命 | 100 | 可由 Buff 提升 |
| 基礎攻擊力 | 20 | 一次揮擊對單一目標造成的基礎傷害 |
| 攻擊距離 | 88 px（約 1.8 格） | 以玩家中心到敵人中心計算；比原 72 px 增加 16 px |
| 攻擊扇形 | 100° | 朝玩家面向前方 |
| 揮擊間隔 | 0.45 秒 | 攻擊期間不可重複觸發 |
| 受傷無敵 | 0.6 秒 | 避免被多個碰撞框瞬間秒殺 |
| 移動速度 | 4 格／秒 | 以遊戲內格子作為邏輯單位 |
| 閃避冷卻 | 1.2 秒 | 閃避開始時立刻進入冷卻 |
| 閃避位移 | 1.5 格 | 沿輸入方向快速位移 |
| 閃避無敵 | 0.18 秒 | 只免疫傷害，不免疫房間邊界與不可行走地形 |
| 初始藥水 | 0 | 藥水由房間獎勵取得 |

## 3. 操作

| 行為 | 桌面操作 | 行動版建議 |
|---|---|---|
| 移動 | WASD／方向鍵 | 右側虛擬搖桿 |
| 面向 | 移動方向 | 右側虛擬搖桿方向 |
| 近戰攻擊 | Space | 左側攻擊按鈕 |
| 閃避 | Shift | 左側閃避按鈕 |
| 暫停 | Esc／P | 暫停按鈕 |

電腦版只支援鍵盤，不支援滑鼠移動、瞄準、攻擊、閃避或選單操作。玩家以移動方向決定面向；停止移動時保留最後面向。

手機版只支援橫式畫面：左側提供攻擊與閃避，右側提供虛擬搖桿；不使用獨立的右側攻擊或瞄準按鈕。

## 4. 閃避

閃避是第一階段的正式核心操作，讓近戰玩家能主動穿過攻擊預警、離開包圍或在 Boss 攻擊後接近反擊。

- 玩家按下閃避時，沿當下移動輸入方向位移；沒有方向輸入時，沿目前面向位移。
- 閃避位移約 1.5 格，持續時間約 0.22 秒，其中前 0.18 秒具有無敵效果。
- 閃避開始時立即進入 1.2 秒冷卻，HUD 必須顯示冷卻狀態。
- 閃避不能穿越牆壁、封閉門或不可行走格；碰到障礙物時，位移在可行走位置停止。
- 閃避期間不能發動近戰攻擊；閃避結束後保留約 0.08 秒的動作恢復時間，避免無縫取消所有風險。
- 無敵時間只免疫傷害與受擊，不會解除房間封鎖，也不會跳過陷阱的地形限制。
- 閃避成功避開攻擊時可播放短暫殘影或音效；第一階段先不設計反擊傷害，避免系統過度複雜。
- Buff 可以降低冷卻或增加位移，但不得讓冷卻低於 0.55 秒，避免玩家永久處於無敵循環。

## 5. 近戰攻擊判定

- 攻擊開始時記錄玩家面向，揮擊過程不自動追蹤目標。
- 傷害碰撞區只存在於揮擊的有效幀，不用整個攻擊動畫持續造成傷害。
- 同一個揮擊對同一個敵人最多命中一次。
- 每次有效揮擊都播放 Shoot 'em up 素材包 `1 Main Character/3 Effects/1_1.png` 的方向性白金色斬擊波；特效依攻擊開始時的面向旋轉，長度須與 88 px 判定範圍接近。
- 命中敵人時播放短暫受擊閃白、擊退與命中音效；命中多個敵人時仍只播放一次主要音效。
- 攻擊落空仍消耗揮擊間隔，避免玩家無腦連按沒有風險。
- 近戰傷害公式：

  `實際傷害 = max(1, 攻擊力 × 乘區倍率 + 固定加成 - 敵人護甲)`

第一階段先不加入複雜護甲，保留公式是為了後續擴充。

## 6. 受傷與死亡

- 敵人接觸、敵人攻擊或陷阱命中玩家時造成傷害。
- 玩家被敵人接觸、近戰、衝撞或投射物命中時，沿傷害來源反方向短暫擊退約 14～20 像素；擊退期間暫時取代移動輸入，但仍受牆壁與關閉房門邊界限制。
- 受傷時玩家閃爍並進入短暫無敵，期間不重複扣血。
- 生命降至 0 時停止輸入、播放死亡動畫並進入 `defeat`。
- 死亡不保留本次 Run 的 Buff；第一階段不設永久成長。

## 7. 近戰武器方向

所有武器都是近戰，只改變攻擊形狀或節奏：

| 武器類型 | 特性 | 代價 |
|---|---|---|
| 長劍 | 平衡的扇形攻擊 | 無特殊效果 |
| 闊斧 | 傷害高、扇形大 | 揮擊間隔較長 |
| 戰鎚 | 小範圍高擊退 | 攻擊距離較短 |
| 機械刃 | 攻擊快，可疊加機械標記 | 單次傷害較低 |

機械射擊素材中的槍械圖示只作為「機械刃模組」或其他近戰遺物的圖示，不代表玩家可以射擊。
