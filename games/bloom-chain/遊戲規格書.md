| 名稱 | 英文副名 | 命名方向 |
| --- | --- | --- |
| **花漾連鎖** | **Bloomshift** | 花朵綻放與盤面交換、連鎖的節奏感兼具，建議採用。 |

本規格採用《花漾連鎖》。宣傳短句：**交換花瓣，讓連鎖一路綻放。**

## 二、遊戲概述

《花漾連鎖》是一款即時面板配對益智遊戲。玩家在不斷上升的花園盤面上，交換左右相鄰的花瓣面板，讓三個以上相同花紋排成直線並消除。面板下落後可能接續形成連鎖；玩家也能在消除動畫期間繼續交換面板，主動安排下一輪連鎖。盤面升到頂端即告失敗，玩家要在壓力下快速整理盤面、把握連鎖機會並盡量生存更久。

遊戲採用原創的花園、芽靈、花瓣符號與美術設定。玩法靈感來自即時交換面板、三連消除、上升盤面與主動連鎖等益智遊戲機制；不使用其他作品的角色、故事、名稱、圖像、音效或關卡素材。

### 2.1 核心樂趣

- 快速交換相鄰面板，清出可操作空間。
- 預判面板下落位置，安排重力連鎖。
- 在消除過程中繼續操作，主動接上連鎖。
- 盤面愈升愈快時，權衡立即消除與佈置大連鎖。

### 2.2 目標玩家

- 喜歡即時益智、配對消除與高分挑戰的玩家。
- 想用短局遊玩、逐步練習反應與盤面判讀的玩家。
- 桌面與手機瀏覽器使用者。

## 三、第一版產品範圍

### 3.1 必須完成

- 6 欄 × 12 列的面板盤面，開始時由底部填入 6 列。
- 五種可辨認的花瓣面板，顏色與圖形符號雙重區分。
- 游標選取左右相鄰兩格，交換兩格面板。
- 三個以上相同面板水平或垂直相連時消除。
- 消除、下落、重力連鎖與消除期間的主動連鎖操作。
- 盤面定時從底部上升，新的一列由底部加入。
- 無盡生存與 120 秒限時挑戰兩種單人模式。
- 分數、連鎖數、最高分、本局最佳連鎖與遊戲結束畫面。
- 鍵盤、滑鼠與觸控操作；暫停、重新開始與操作說明。
- 本機保存最高分與音效設定。
- 手機直向與桌面版自適應版面；色弱輔助與減少動態效果設定。

### 3.2 第一版不包含

- 即時連線、玩家對戰、電腦對手與排行榜。
- 故事關卡、芽靈收集、道具、技能或付費內容。
- 每日任務、帳號、雲端存檔與玩家自製關卡。

## 四、遊戲模式與流程

### 4.1 無盡生存

- 盤面持續上升，消除面板可取得分數並延長生存時間。
- 上升速度隨時間增加，挑戰玩家能維持多久及達到多少分。
- 任一面板被新一列推離盤面頂端時，遊戲結束。

### 4.2 限時挑戰

- 回合固定 120 秒；時間到時結束並結算分數。
- 面板上升速度仍會隨時間增加，讓後半局逐步升壓。
- 若面板先被推離盤面頂端，回合立即結束並記錄當前分數。

### 4.3 核心遊戲流程

1. 玩家選擇模式，系統建立盤面並放入起始面板。
2. 玩家選取一對水平相鄰面板並交換位置。
3. 系統判定直線上是否有三個以上相同面板。
4. 符合條件的面板短暫閃爍後消除；玩家可在消除與下落期間繼續交換其他面板。
5. 上方無支撐的面板往下落，重新檢查是否形成新消除。
6. 重複消除與下落，直到盤面穩定；本回合連鎖結算完成。
7. 上升計時到期時，盤面整體上移一列並由底部加入新列。
8. 檢查失敗條件或限時是否結束；若尚未結束則繼續遊玩。

## 五、盤面與面板規則

### 5.1 盤面尺寸與座標

| 項目 | 設定 |
| --- | --- |
| 盤面 | 6 欄 × 12 列 |
| 座標原點 | 左上角 `(0, 0)` |
| X 範圍 | `0～5`，由左至右 |
| Y 範圍 | `0～11`，由上至下 |
| 起始填入 | 最底部 6 列，保留上方 6 列空間 |
| 游標 | 2 格寬 × 1 格高，可選擇的左側欄位為 `0～4` |

盤面以固定欄列資料保存。消除、下落與上升動畫只負責呈現，不得改變已完成的邏輯判定結果。

### 5.2 面板種類與生成

- 一般面板共五種：玫紅、金黃、葉綠、湖藍、薰紫。
- 每種顏色另搭配固定花瓣／葉片符號與紋理，不可只靠顏色辨認。
- 起始盤面與新增底列以可重現的偽隨機方式生成。
- 生成底列時避免直接產生三個以上的水平同色連線。
- 遊戲開始時至少存在兩種有效交換，避免一開局就無法操作。
- 盤面不主動生成障礙、特殊面板或道具。

### 5.3 交換規則

- 每次交換游標覆蓋的水平相鄰兩格。
- 兩格至少有一格含有面板時才執行交換；兩格皆空則不動作。
- 盤面消除與下落動畫播放時仍可操作；被標記為正在消除的格子不能作為交換目標。
- 交換後若未形成消除，面板仍留在新位置，不會自動換回。
- 僅能水平交換，不能垂直交換或旋轉面板。

### 5.4 盤面上升

- 起始上升間隔為每 9 秒一列。
- 每經過 45 秒，上升間隔縮短 0.4 秒，最快縮短至每 3.8 秒一列。
- 上升計時在消除與下落時仍持續累積；盤面正在解析時到期的上升最多暫存 2 列。暫存達上限後暫停計時，盤面穩定時先執行待升列，再繼續計時。
- 上升時所有面板往上移一列，最底列加入新的隨機面板。
- 畫面頂列出現面板時，頂端邊框轉為警示色並播放提示；之後若上升使面板離開盤面，就立即結束回合。
- 暫停時停止上升計時；恢復時從暫停前的剩餘時間繼續。

## 六、消除、下落與連鎖

### 6.1 消除判定

- 只檢查水平與垂直相鄰位置，斜角不相連。
- 同一顏色在同一水平線或垂直線連續三格以上，即形成消除組。
- 一次判定可以同時消除多條相交或分離的連線；交疊格只計算一次。
- 相交或相連的消除線合併計為一組；彼此分離的消除群組分開計數。
- 面板交換成立後延遲 100 毫秒再判定，避免動畫期間重複判定。
- 消除標記持續 320 毫秒，接著移除面板並套用重力。

### 6.2 下落與重力連鎖

1. 同輪所有符合條件的面板一起標記。
2. 播放閃爍與消除動畫；期間玩家可交換未被標記的面板。
3. 移除該輪面板，讓每一欄剩餘面板向下填補空格。
4. 下落完成後重新掃描消除條件。
5. 若形成新消除，連鎖層數加一並重複以上流程。
6. 若沒有新消除，結束本回合的連鎖結算。

### 6.3 主動連鎖

- 玩家可在消除動畫或面板下落期間操作，預先交換下一組面板。
- 在目前消除輪次結束前新形成的消除，會先標記為待處理並高亮；待處理面板暫時不能交換。當前輪面板移除並完成重力後，待處理面板接續消除，即使下落改變了它們原本的位置。
- 由下落形成或由玩家在解析期間安排的下一輪消除，都會增加連鎖層數。
- 同一輪同時消除多條線屬於「同時消除加成」，不會各自增加連鎖層數。
- 每輪消除後最多接受 4 次有效交換，避免動畫時間內無限操作；每次成功交換都會立即更新待處理消除。

### 6.4 無效與邊界處理

- 游標不得超出盤面；到達最左或最右端時，後續移動輸入不產生效果。
- 正在消除的面板不可移動，也不能被其他面板覆蓋。
- 連續上升到期時若盤面仍在解析，最多排隊 2 列；盤面穩定後立即執行，超過上限的上升仍按計時器保留，不額外補列。
- 畫面切到背景分頁時自動暫停並顯示「點擊繼續」，避免瀏覽器節流造成盤面瞬間跳動。

## 七、計分與難度

### 7.1 分數

```text
本輪基本分 = 本輪消除面板數 × 10
連鎖加分 = 本輪基本分 × (連鎖層數 - 1) × 0.5
同時消除加分 = max(0, 本輪分離消除組數 - 1) × 50
本輪得分 = 本輪基本分 + 連鎖加分 + 同時消除加分
```

- 第一輪消除視為第 1 連鎖，只有第 2 輪起取得連鎖加分。
- 每次盤面上升本身不加分；玩家需透過消除面板取得分數。
- 顯示目前分數、本局最高連鎖、存活時間與目前上升速度。
- 各模式分開保存最高分；限時挑戰另保存最佳單局連鎖。

### 7.2 難度曲線

- 無盡生存與限時挑戰使用相同上升速度曲線。
- 每 45 秒縮短上升間隔 0.4 秒，縮短至 3.8 秒後維持固定速度。
- 速度變化前顯示 2 秒提示，並以邊框節奏、音效或文字明確提示壓力增加。
- 不隨時間增加面板種類，確保難度主要來自速度而非規則變複雜。

## 八、操作與介面

### 8.1 桌面操作

| 操作 | 按鍵 |
| --- | --- |
| 移動游標 | 方向鍵或 `WASD` |
| 交換選取面板 | `Space` 或 `Enter` |
| 暫停／繼續 | `Esc` 或 `P` |

滑鼠點擊一格可將游標定位在該格及其右側相鄰格；若點擊最右欄，則選取其左側相鄰格。點擊游標框內的任一格可執行交換。

### 8.2 行動裝置操作

- 點擊盤面移動游標；若點擊最右欄，則選取其左側相鄰格。再次點擊游標框內的任一格即可交換。
- 水平滑動一格可直接交換該方向相鄰面板。
- 螢幕提供固定的暫停按鈕與清楚的游標高亮，避免手指遮住目標格。
- 觸控操作不得依賴懸停狀態；按鈕觸控範圍至少 44 × 44 CSS 像素。

### 8.3 畫面資訊

- 主畫面：遊戲標題、無盡生存、限時挑戰、操作說明、設定。
- 遊戲畫面：盤面、游標、分數、計時／存活時間、連鎖提示、上升警示、暫停按鈕。
- 暫停畫面：繼續、重新開始、返回主選單、音效與動態效果設定。
- 結束畫面：本局分數、最佳紀錄、最高連鎖、再玩一次、返回主選單。

## 九、視覺與音效方向

- 主題為晨光中的原創芽靈苗圃；面板表現為不同花朵、種子或葉片圖樣。
- 棋盤背景保持低對比，確保面板邊界與游標清楚。
- 消除使用短促綻放粒子；連鎖層數愈高，音高與光效逐步提升。
- 上升提示使用畫面頂端邊框、圖示及文字共同表達，不只依賴顏色或閃爍。
- 設定包含音效開關、音量、減少動態效果與高對比面板樣式。
- 音效及圖像需原創或使用授權素材，並記錄素材來源。

## 十、資料保存

使用瀏覽器 `localStorage` 保存：

```json
{
  "version": 1,
  "bestScore": { "endless": 0, "timeAttack": 0 },
  "bestChain": { "endless": 0, "timeAttack": 0 },
  "settings": {
    "soundEnabled": true,
    "soundVolume": 0.7,
    "reducedMotion": false,
    "highContrastPanels": false
  }
```

- 每次回合結束後更新對應模式的最高分與最佳連鎖。
- 讀取資料失敗、格式錯誤或版本不符時，使用預設設定並重新建立存檔。
- 第一版不保存進行中的盤面與雲端資料。

## 十一、驗收條件

- 能以鍵盤、滑鼠與觸控選取並交換左右相鄰面板。
- 任一直線中三個以上相同面板可正確消除；斜角相鄰不會誤消。
- 同輪多條消除線不重複計算面板；分數與同時消除加分正確。
- 面板消除後會正確下落，並能由下落或主動交換觸發後續連鎖。
- 解析期間的有效交換不會移動正在消除的面板，且待處理消除能正確結算。
- 盤面依設定速度上升並由底部加入新列；面板被推離頂端時正確結束回合。
- 暫停、分頁背景暫停、重新開始及兩種模式的結束條件正確。
- 最高分、最佳連鎖與設定在重新載入頁面後仍保留。
- 手機直向版面可操作，五種面板在高對比模式下不只依賴色相辨識。
