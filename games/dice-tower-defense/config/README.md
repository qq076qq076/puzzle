# 遊戲設定檔索引

本目錄只存放可調整的靜態設定。戰鬥流程、狀態更新與 Canvas 繪圖仍由上一層 `script.js` 負責。

| 檔案 | 負責內容 |
| --- | --- |
| `game-config.js` | 經濟、核心初始值、存檔鍵與特效數量上限 |
| `board-config.js` | 棋盤尺寸、S 型道路座標、道路素材與放置高亮 |
| `tower-config.js` | 骰塔傷害、射程、攻速、爆擊、施工、合成動畫與類型圖紙 |
| `enemy-config.js` | 怪物生命、速度、漏怪傷害、獎勵、能力參數、尺寸、抗性、顏色，以及各類型的素材、模型比例與底盤半徑 |
| `wave-config.js` | 30 波編隊、出場間隔、數量倍率、金幣倍率與終盤護盾起始波次 |

新增骰塔或怪物時，除了加入類型設定，也要確認 `script.js` 中對應的攻擊、能力及繪圖分支。設定模組不得操作 DOM、Canvas、存檔或執行戰鬥流程。
