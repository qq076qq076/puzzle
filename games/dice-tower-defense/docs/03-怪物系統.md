# 怪物系統

> 文件版本：0.20
> 上層索引：[README.md](./README.md)

## 2. 共通資料結構

敵人物件至少包含：

```js
{
  id,
  order,
  type,
  pathDistance,
  hp,
  maxHp,
  speed,
  movementDelayRemaining,
  shield,
  resistances: {
    freeze: 0,
    lightning: 0,
    poison: 0,
    physical: 0
  },
  slow,
  slowRemaining,
  frozenRemaining,
  poisonRemaining,
  poisonDps,
  healingCooldown,
  invisibleRemaining,
  dead
}
```

類型能力可另外使用 `healerTimer`、`mageTimer`、`wardTimer`、`burrowTimer`、`disruptTimer`、`regenDelayRemaining`、`berserkTriggered` 或首領計時器。不得保存或套用單一 `allResistance`／`waveResistance`。

## 3. 特定抗性

遊戲沒有全傷害抗性。第 13 波起，每種怪物只取得表中指定的一至兩種抗性：

```text
waveResistanceStrength(wave) = wave <= 12
  ? 0
  : combine(
      min(0.36, (wave - 12) × 0.02),
      wave <= 15 ? 0.03 : wave <= 25 ? 0.06 : 0.10
    )

combine(a, b) = 1 - (1 - a) × (1 - b)
```

| 波次 | 指定抗性強度 |
| ---: | ---: |
| 1～12 | 0% |
| 13 | 4.94% |
| 20 | 21.04% |
| 25 | 30.44% |
| 30 | 42.40% |

### 3.1 抗性效果

| 抗性 | 只影響 | 不影響 |
| --- | --- | --- |
| 冰凍 `freeze` | 霜凍骰造成的減速與爆擊冰凍持續時間 | 霜凍直接傷害、其他傷害與狀態 |
| 雷電 `lightning` | 連鎖骰主目標及所有跳躍傷害 | 炮擊、霜凍、毒蝕、穿刺、刃擊 |
| 毒素 `poison` | 毒蝕直接命中、爆擊範圍傷害及每秒毒傷 | 中毒持續時間與其他骰塔 |
| 物理 `physical` | 炮擊主傷害、炮擊爆炸、穿刺及刃擊傷害 | 霜凍、毒蝕、連鎖與控制 |

傷害計算順序：

```text
原始傷害
  → 對應特定抗性
  → 護盾吸收
  → 剩餘生命傷害
```

冰凍抗性直接作用於持續時間：

```text
最終減速時間 = 2.0 × (1 - freezeResistance)
最終冰凍時間 = 1.2 × (1 - freezeResistance)
```

裝甲蟲的常駐 35% 物理抗性與波次物理抗性採乘法合併：

```text
armorPhysicalResistance = 1 - (1 - 0.35) × (1 - waveResistanceStrength)
```

第 13／20／25／30 波約為 38.2%／48.7%／54.8%／62.6%。任何怪物最多兩種特定抗性，不得同時抵抗全部四類。

### 3.2 視覺辨識

- 青色 `❄`：冰凍抗性。
- 黃色 `⚡`：雷電抗性。
- 綠色 `☣`：毒素抗性。
- 銀色 `◆`：物理抗性。
- Canvas 以對應顏色的分段虛線環與小型 icon 顯示實際抗性。
- 棋盤下方保留同色圖例，不使用代表全抗性的單一灰環。

## 4. 共通狀態規則

- `movementDelayRemaining > 0` 的畫面外敵人不更新任何狀態或能力。
- 減速不疊加比例，只保留較強值並刷新為較長的剩餘時間。
- 冰凍期間移速為 0；冰凍結束後恢復當時仍有效的減速。
- 成功受到刃擊骰擊退時沿道路後退 0.5 格。一般怪物的擊退保護為 `clamp(1.35 ÷ 當下移速, 0.75, 2.0)` 秒；當下移速需計入波次速度、減速、加速、潛地與狂暴。首領固定為 2.5 秒，具有隱形能力的怪物永久為 0 秒，傷害與其他狀態不受影響。
- 中毒不疊層；再次命中刷新時間，並保留較高每秒傷害。
- 毒傷使敵人死亡後，本幀不再執行治療、結界、潛地、干擾或首領能力。
- 隱形與潛地中的敵人不可成為新單體、範圍毒蝕、連鎖或穿刺目標。
- 已存在的中毒仍可在隱形或潛地期間結算。
- 已發射的投射物可以命中發射後才進入隱形的原目標。
- 敵人死亡與漏怪同幀時，死亡優先。

## 5. 一般怪物能力

### 5.1 分裂蟲

- 死亡時在原位置後方生成 2 隻分裂幼體。
- 幼體不再分裂。
- 幼體與首領召喚物不套用波次段落數量倍率，但使用當前波次生命、速度、護盾與抗性。

### 5.2 幽影蟲

- 進場後每 6 秒進入 1 秒隱形。
- 隱形時不可被新索敵，既有中毒仍結算。
- 由於具有隱形能力，即使當下處於現形狀態，成功被擊退後也不取得擊退保護。

### 5.3 治療法師

- 每 8.5 秒治療半徑 2 格內其他敵人最大生命的 5%。
- 不治療自己、滿血或尚在受治療冷卻的目標，不超過目標最大生命。
- 每隻怪物成功受治療後獨立進入 6 秒受治療冷卻；冷卻期間不能再被任何治療法師治療。
- 每 12 秒施放封印，從半徑 2.6 格內隨機選擇 1 座非施工骰塔停火 0.7 秒。
- 封印期間骰塔攻擊冷卻暫停，不攻擊也不發鼓舞脈衝。
- 施工倒數仍正常進行；波次結束時清除殘餘封印。

### 5.4 結界蟲

- 首次施法依生成順序錯開，之後每 5.25 秒施法。
- 把半徑 2.2 格內其他在場敵人的護盾提高至最大生命 8%。
- 不保護自己、不治療生命、不累加超過 8%。

### 5.5 潛地蟲

- 進場約 4 秒後首次潛地，之後每次浮出 5.5 秒後再施放。
- 潛地持續 1.25 秒，期間不可成為新目標，移速乘以 1.65。
- 冰凍仍可讓移速歸零，既有中毒仍結算。

### 5.6 干擾蟲

- 每 6 秒檢查半徑 2.6 格內非施工骰塔。
- 每座受影響塔的目前冷卻延後 0.45 秒。
- 冷卻最多推至該塔完整攻擊間隔的 1.5 倍。
- 不改變永久攻速、不建立施工或封印狀態。

### 5.7 再生蟲

- 每次承受直接或持續傷害，把 `regenDelayRemaining` 重設為 2.5 秒。
- 倒數歸零且生命未滿時，每秒恢復最大生命 2%。
- 持續毒傷會持續重設倒數，因此可阻止再生。

### 5.8 狂暴蟲

- 生命首次降至最大生命 50% 以下時，設定 `berserkTriggered = true`。
- 狂暴後永久維持 1.7 倍移速，即使被治療到半血以上也不解除。
- 仍可被減速與冰凍控制。

### 5.9 掠金蟲

- 抵達城門時先造成 1 點核心傷害。
- 再扣除 `min(目前金幣, 12)`，金幣不得低於 0。
- 有實際扣款時播放金幣飛散與整數 `-N G` 浮字。

## 6. 首領規則

所有首領首次正式進入戰場時，先從畫面上方落向道路入口。落地前不可被攻擊且不移動；落地瞬間播放地面陰影、塵環、衝擊波與短暫鏡頭震動，之後才開始移動與施放能力。降低特效模式保留落地辨識，但減弱或取消鏡頭震動。

### 6.1 巨甲王

- 護盾是獨立 `shield` 數值，傷害先經特定抗性再扣護盾。
- 護盾歸零不造成停頓或硬直，只播放一次 0.72 秒護盾爆炸。
- 第 5 波：3 點基礎護盾。
- 第 10 波：6 點護盾，半血時一次召喚 4 隻迅捷蟲。
- 第 15 波：10 點護盾，每 8 秒使所有非首領敵人加速 20%，持續 3 秒。
- 第 20 波起：14 點基礎護盾。
- 第 25 波巨甲王不召喚迅捷蟲。
- 第 28～30 波取基礎護盾與波次比例護盾的較高值。

### 6.2 裂界巨甲王

- 每 7 秒把半徑 3.2 格內包含自己的敵人護盾提高至最大生命 8%。
- 同一次施法把半徑 3.6 格內非施工骰塔冷卻延後 0.35 秒。
- 結界與干擾在同一邏輯更新發生，但用不同動畫表現。
- 不使用巨甲王半血召喚行為。
- 第 30 波每隻具有 20% 最大生命護盾。

### 6.3 首領死亡

- 首領死亡播放 1.35 秒多層爆炸。
- 護盾破裂只播放獨立 0.72 秒爆炸，不修改移動、戰鬥時間或全局 `deltaTime`。
- 首領召喚物計入本波剩餘敵人，但不增加額外波次獎勵。

## 7. 視覺與建模

- 怪物使用 Kenney Tiny Dungeon 16×16 CC0 PNG；來源與映射見[怪物素材說明](../assets/enemies/README.md)。
- Canvas 關閉影像平滑，維持最近鄰像素邊緣。
- sprite、底盤、陰影、狀態環與血條統一使用原始繪製基準的 `9 / 8`，即上一版的 1.5 倍；不改變碰撞、路徑或索敵。
