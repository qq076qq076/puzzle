## 規格責任邊界

- 骰塔傷害、攻速、射程、爆擊與合成數值只修改「骰子系統」。
- 怪物生命、速度、抗性與能力只修改「怪物系統」。
- 哪一波出現哪些怪物、數量倍率與波次護盾只修改「關卡與波次」。
- 輸入手勢、按鈕、資訊顯示與視覺回饋只修改「操作與介面」。
- 狀態更新順序、資料格式、效能與測試案例只修改「技術與測試」。
- 若一項變更跨越多個主題，先修改擁有該數值的文件，再於其他文件加入連結或驗收案例，不複製完整規則。

## 版本更新規則

目前所有主題文件使用同一版號 `0.20`。核心循環、資源、勝負條件、骰塔／怪物數值或波次配置改變時，應同步更新本索引與受影響文件的版本號。純文字修正、連結調整或不影響規則的排版修改可不升版。

## 快速入口

- 要調整一局怎麼進行：看[遊戲規則](./01-遊戲規則.md)。
- 要調整骰塔強弱：看[骰子系統](./02-骰子系統.md)。
- 要新增怪物或抗性：看[怪物系統](./03-怪物系統.md)。
- 要重排第幾波出怪：看[關卡與波次](./04-關卡與波次.md)。
- 要修改拖曳、選取或 HUD：看[操作與介面](./05-操作與介面.md)。
- 要確認實作順序或驗收：看[技術與測試](./06-技術與測試.md)。
