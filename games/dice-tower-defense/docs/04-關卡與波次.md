# 關卡與波次

> 文件版本：0.20
> 上層索引：[README.md](./README.md)

本文件是 30 波編隊、波次倍率、準備時間與終盤護盾的唯一來源。怪物基礎生命、速度、抗性與能力見[怪物系統](./03-怪物系統.md)。

## 1. 波次建立規則

- 波次開始時一次建立全部敵人，不保留逐隻生成佇列。
- 每個編隊段落的 `interval` 依順序累加成 `movementDelayRemaining`。
- 第一隻延遲為 0；等待中的敵人站在畫面外 `x = -1.5`。
- 畫面外敵人存在於 `state.enemies`，但 `isEnemyOnField(enemy) = false`。
- 延遲歸零的同一幀播放一次入口光圈，並只用剩餘 `deltaTime` 移動。
- 分裂幼體與首領召喚物不是波次段落，不套用段落數量倍率，生成後立即移動。
- 波次敵人、分裂幼體與召喚物全部死亡或漏怪離場後，才進入結算。

## 2. 難度成長

第 8 波起使用綜合難度分段。目標倍率不是只把怪物變成血包，而是由生命、速度與既有的特定抗性共同構成：

| 波次 | 目標綜合難度 | 額外生命倍率 | 額外速度倍率 | 指定抗性額外係數 |
| ---: | ---: | ---: | ---: | ---: |
| 1～7 | 1× | 1.00× | 1.00× | 0% |
| 8～15 | 約 2× | 1.85× | 1.08× | 3%（第 13 波起） |
| 16～25 | 約 3× | 2.55× | 1.10× | 6% |
| 26～30 | 約 5× | 4.10× | 1.12× | 10% |

抗性額外係數只與怪物原本指定的一至兩種抗性合併，不會建立全抗性。速度與抗性帶來的控制、輸出窗口壓力，使綜合難度接近目標值；它不是所有隊伍都完全相同的精確數學倍率。

### 2.1 數量

```text
第 1～10 波：actualCount = Math.round(baseCount × 2.5)
第 11～30 波：actualCount = Math.round(baseCount × 2.5 × 1.2)
                         = Math.round(baseCount × 3.0)
```

正數 `.5` 依 JavaScript `Math.round` 向上取整。

### 2.2 生命

第 1～10 波維持既有公式：

```text
legacyBase(wave) = 1
  + (wave - 1) × 0.12
  + max(0, wave - 4) × 0.03
  + max(0, wave - 9) × 0.04

legacyMultiplier(wave) = legacyBase(wave)
  × (wave <= 5 ? 1.00 : 1.25)

hpMultiplier(5) = legacyMultiplier(5) × 0.59
```

第 5 波額外套用 `0.59`，使首領波總生命相較原配置下降約 41%；第 6 波透過編隊數量調整，總生命略高於第 5 波，避免難度倒退。

第 10 波 `2.875×` 是後段錨點：

```text
progress(wave) = wave <= 10 ? 1
               : wave <= 20 ? 1 + (wave - 10) × 0.2
               : min(5, 3 + (wave - 20) × 0.2)

hpMultiplier(wave) = wave <= 10
  ? legacyMultiplier(wave)
  : 2.875 × progress(wave)

difficultyHp(wave) = wave <= 7 ? 1.00
                   : wave <= 15 ? 1.85
                   : wave <= 25 ? 2.55
                   : 4.10

finalHpMultiplier(wave) = hpMultiplier(wave) × difficultyHp(wave)
```

| 波次 | 生命倍率 |
| ---: | ---: |
| 1 | 1.00× |
| 5 | 0.8909× |
| 6 | 2.075× |
| 8 | 4.5325× |
| 10 | 5.3188× |
| 11 | 6.3825× |
| 15 | 10.6375× |
| 16 | 16.1288× |
| 20 | 21.9938× |
| 21 | 23.46× |
| 25 | 29.325× |
| 26 | 49.5075× |
| 28 | 54.2225× |
| 29 | 56.58× |
| 30 | 58.9375× |

- 最終生命四捨五入為整數。
- 所有首領再乘以 `1.25`。

### 2.3 速度

```text
growthSpeed = min(baseSpeed × (1 + (wave - 1) × 0.015), baseSpeed × 1.35)

difficultySpeed(wave) = wave <= 7 ? 1.00
                      : wave <= 15 ? 1.08
                      : wave <= 25 ? 1.10
                      : 1.12

finalSpeed = min(growthSpeed × difficultySpeed(wave), baseSpeed × 1.50)
```

能力造成的加速、潛地與狂暴乘數在最終基礎速度之後計算。

### 2.4 特定抗性

第 13 波起，怪物先取得每波 +2%、最高 36% 的基礎指定抗性，再與難度分段的 3%／6%／10% 額外係數採乘法合併。抗性類型與效果由[怪物系統](./03-怪物系統.md#3-特定抗性)定義；本系統不產生全傷害抗性。

### 2.5 護盾

- 第 1～27 波只有怪物能力或首領基礎規則提供護盾。
- 第 28 波：所有生成物取得最大生命 12% 護盾。
- 第 29 波：所有生成物取得最大生命 16% 護盾。
- 第 30 波：所有生成物取得最大生命 20% 護盾。
- 分裂幼體與首領召喚物同樣取得目前波次比例護盾。
- 首領取比例護盾與自身基礎護盾的較高值。

### 2.6 擊殺金幣

第 1～30 波都使用 `max(1, round(怪物基準獎勵 × 1/3))` 的整數金幣，不再於後期額外乘 70%。完整資源規則見[遊戲規則](./01-遊戲規則.md#51-金幣)。

## 5. 關卡節奏

- 第 1～3 波：只教導基本敵人、部署與輸出。
- 第 4～10 波：導入首領、分裂與隱形。
- 第 11～15 波：導入治療、封印、再生與特定抗性。
- 第 16～20 波：導入狂暴、掠金與高密度快慢交錯。
- 第 21～24 波：大規模精英混編。
- 第 25 波：24 隻巨甲王壓力檢查點。
- 第 26～27 波：結界、潛地與新怪組合。
- 第 28～29 波：干擾、掠金及全員比例護盾。
- 第 30 波：9 隻裂界巨甲王，不包含其他編隊怪物。
