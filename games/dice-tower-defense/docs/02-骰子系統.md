# 骰子系統

> 文件版本：0.20
> 上層索引：[README.md](./README.md)

本文件是所有骰子、骰塔、攻擊、爆擊、施工與合成數值的唯一來源。敵人抗性如何回應各攻擊類型，見[怪物系統](./03-怪物系統.md#3-特定抗性)。

## 1. 共通資料

每座骰塔至少包含：

| 欄位 | 規格 |
| --- | --- |
| `type` | `cannon`、`frost`、`poison`、`chain`、`pierce`、`blade`、`inspire` |
| `tier` | 1～6；所有新骰子固定從 1 級開始 |
| `x`, `y` | 建造格座標 |
| `cooldown` | 下一次可攻擊／脈衝前的剩餘秒數 |
| `forcedCrit` | 下一次有效攻擊是否必定爆擊 |
| `buildDuration`, `buildRemaining` | 戰鬥中施工總時間與剩餘時間 |
| `attackDisabledRemaining` | 法師封印造成的停火剩餘時間 |
| `totalInvested` | 出售返還的計算基礎 |

不保存獨立 `face` 或特殊充能。骰面 icon 數量就是等級。

## 2. 骰面與等級視覺

| 等級 | icon 排列 |
| ---: | --- |
| 1 | 中央 1 個 |
| 2 | 左上、右下 |
| 3 | 左上、中央、右下 |
| 4 | 四角 |
| 5 | 四角與中央 |
| 6 | 左右兩列的上、中、下 |

- icon 形狀代表骰種，數量代表等級。
- 不顯示阿拉伯數字、左上角等級、右下角類型徽章或獨立骰面欄位。
- 待建造骰子、場上骰塔、購買區、拖曳預覽與合成飛入動畫使用相同正方形骰面。
- 場上骰塔邊長約 `0.72 格`，建造平台邊長約 `0.76 格`。

## 3. 自然爆擊

| 等級 | 非霜凍骰 | 霜凍骰 |
| ---: | ---: | ---: |
| 1 | 10% | 2% |
| 2 | 20% | 3% |
| 3 | 35% | 4% |
| 4 | 48% | 6% |
| 5 | 60% | 8% |
| 6 | 72% | 10% |

- 只有有合法目標、即將執行有效攻擊時才擲爆擊。
- 自然爆擊使該次主要傷害乘以 `1.75`，並觸發骰種爆擊能力。
- `forcedCrit = true` 時，下一次有效攻擊直接爆擊並清除旗標，不擲自然爆擊。
- 鼓舞骰提供的強制爆擊不受霜凍骰低自然爆擊率影響。
- 爆擊不改變攻擊冷卻。
- 合成後清除目標骰塔的 `forcedCrit`；移動不清除。

| 霜凍骰 | 控制 | 傷害 2.4、射程 3、間隔 0.42s、減速 20% | 4.8、3.5、0.40s、28% | 11.7、4、0.38s、38% | 20.7、4.5、0.35s、48% | 40、5、0.32s、58% | 68、5.5、0.29s、68% |
| 毒蝕骰 | 毒素、持續傷害 | 傷害 1.6、射程 2.5、間隔 0.38s、中毒 4s | 3.2、3、0.36s、5s | 9、3.5、0.34s、6s | 16.2、4、0.31s、7s | 32、4.5、0.28s、8s | 56、5、0.25s、9s |
| 連鎖骰 | 雷電、群體 | 傷害 3.2、射程 3、間隔 0.59s、2 個 | 7.2、3.5、0.53s、3 個 | 17.1、4、0.46s、5 個 | 30.6、4.5、0.42s、7 個 | 58、5、0.38s、9 個 | 96、5.5、0.34s、12 個 |
| 穿刺骰 | 物理、直線 | 傷害 4、射程 4、間隔 0.46s、2 個 | 8.8、4.5、0.42s、4 個 | 21.6、5、0.38s、7 個 | 37.8、5.5、0.35s、10 個 | 72、6、0.32s、14 個 | 120、6.5、0.29s、20 個 |
| 刃擊骰 | 物理、範圍擊退 | 傷害 7.2、射程 2、間隔 0.60s | 15.2、2、0.56s | 35、2、0.52s | 63、3、0.49s | 118、3、0.46s | 200、3、0.43s |
| 鼓舞骰 | 輔助 | 相鄰攻速 +8%、間隔 0.59s | +14%、0.52s | +22%、0.46s | +30%、0.41s | +39%、0.37s | +49%、0.33s |

### 4.1 傷害與攻速修正

- 1～2 級攻擊骰的表列傷害已是原始設計值的 80%。
- 3～4 級攻擊骰的表列傷害已是原始設計值的 90%。
- 5～6 級維持原始值。
- 所有攻擊骰再統一乘以 `TOWER_DAMAGE_MULTIPLIER = 0.5`。
- 普通、爆擊、炮擊爆炸、毒傷、毒蝕範圍傷害、連鎖、穿刺與刃擊都使用縮放後傷害，全程保留精度，資訊面板顯示至小數點後 1 位。

攻擊頻率係數為 `[0.5, 0.75, 1, 1, 1, 1]`：

```text
最終間隔 = 表列間隔 ÷ 等級攻擊頻率係數 ÷ (1 + 鼓舞增益)
```

例如 1 級炮擊骰無鼓舞時為 `0.50 ÷ 0.5 = 1.00 秒`；2 級為 `0.42 ÷ 0.75 = 0.56 秒`。鼓舞骰自己的脈衝也套用同一等級頻率係數。

### 4.2 一般與爆擊能力

| 骰塔 | 一般效果 | 爆擊能力 |
| --- | --- | --- |
| 炮擊骰 | 單體物理傷害 | 以目標為中心半徑 1 格造成主傷害 80% 的物理爆炸 |
| 霜凍骰 | 依等級減速，基礎持續 2 秒 | 傷害乘 1.75，並冰凍基礎 1.2 秒 |
| 毒蝕骰 | 中毒每秒造成初始傷害 35%，不疊層，只刷新時間並保留較高 DPS | 以目標為中心，對半徑 1 格內所有合法敵人造成同額毒屬性傷害並附加中毒；不再彈跳 |
| 連鎖骰 | 依序跳向未命中的鄰近敵人；一般衰減為 100%／65%／45%／32%／24%／其後 20% | 連鎖所有射程內合法目標且不衰減 |
| 穿刺骰 | 依道路順序命中射程內指定數量 | 貫穿整條道路中所有合法目標 |
| 刃擊骰 | 只對優先目標造成單體物理傷害，攻擊成功後把自身射程內所有合法怪物沿道路擊退 0.5 格 | 傷害乘 1.75，範圍擊退距離仍為 0.5 格 |
| 鼓舞骰 | 相鄰 8 格其他骰塔取得最高一座鼓舞骰的攻速增益 | 相鄰非鼓舞骰塔取得一次 `forcedCrit` |

鼓舞骰沒有敵方傷害；沒有相鄰非鼓舞骰塔時不擲爆擊。鼓舞骰之間不互相賦予強制爆擊，`forcedCrit` 不累積次數。

刃擊骰只有優先目標承受傷害，其他射程內怪物只受到擊退。一般怪物的擊退保護為 `clamp(1.35 ÷ 當下移速, 0.75, 2.0)` 秒，跑得越快保護越短；首領固定 2.5 秒，具有隱形能力的怪物則為 0 秒。保護期間仍可成為攻擊目標並承受傷害，但不再改變道路進度。擊退不能讓 `pathDistance` 低於 0，且不打斷怪物技能、冰凍或中毒。

## 5. 索敵與攻擊順序

1. 取得射程內、已進場、未死亡、未離場的敵人。
2. 排除隱形、潛地及其他目前不可成為新目標的敵人。
3. 優先選擇剩餘道路較短者。
4. 路徑進度相同時依生成順序，再依敵人 ID 排序。
5. 有合法目標才擲爆擊並建立攻擊事件。
6. 依骰種建立物理、雷電、毒素或無傷害分類的霜凍攻擊。
7. 傷害先套用敵人對應特定抗性，再由護盾吸收，最後扣生命。
8. 建立中毒、減速或冰凍；冰凍抗性在持續時間上計算。
9. 判定死亡、金幣、分裂與特殊觸發。

「有效攻擊」表示至少嘗試命中一個仍存在的合法目標。空路、命中前目標死亡或被不可索敵狀態排除時，不擲爆擊也不消耗 `forcedCrit`。

## 6. 購買與待建造區

- 購買價格：25 金幣。
- 七種骰子均等機率，固定生成 1 級。
- 準備與戰鬥階段都可購買，不設每波或整局數量上限。
- 新骰子進入待建造區並自動選取，不自動占用棋盤。
- 待建造區無容量上限，超出高度時區塊內捲動。
- 購買按鈕使用高對比金色樣式，直接顯示「購買骰子」與「25 G」。

## 7. 放置與施工

- 道路外的 51 格都可放置骰塔。
- 準備階段部署與升級立即完成。
- 戰鬥階段部署 1 級塔需要 1.2 秒。
- 戰鬥中合成為 2～6 級依序需要 2.4／4／5.8／7.8／10 秒。
- `buildRemaining > 0` 時，骰塔不攻擊、不發鼓舞脈衝、不提供攻速、不接受強制爆擊，也不能再合成。
- 施工歸零時冷卻設為 0，播放完工光圈並恢復功能。
- 波次結束後仍在施工的骰塔，在下一個準備階段立即完工。

## 8. 拖曳、交換與合成

- 點擊只負責選取；不建立兩塔合成候選或合成預覽。
- 滑鼠移動超過 10px、觸控超過 14px 才進入拖曳。
- 準備階段可把骰塔拖到空格移動。
- 準備階段拖到不同類型或不同等級骰塔時，交換兩者位置。
- 拖到同類型、同等級、皆完工且低於 6 級的骰塔時直接合成；戰鬥中也允許。
- 拖曳起點是材料，放開位置是保留目標；材料消失，目標升一級。
- 待建造骰子也可拖到同類同級場上骰塔直接合成。
- 6 級為上限；不同類型、不同等級、施工中或非法落點都不能消耗材料。
- 戰鬥中拖到空格或不符合合成條件的骰塔時，維持原位置。

合成動畫：材料骰保留原類型與等級，在 0.55 秒內沿弧線飛向目標；抵達後目標短暫發光，完整動畫約 0.95 秒。

## 9. 出售

- 準備與戰鬥階段都可出售。
- 有效投資額取 `totalInvested` 與該等級重置成本 `25 × 2^(tier - 1)` 的較高值。
- 返還 `floor(有效投資額 × 0.6)` 金幣，最低不得為 0。
- 標準 1～6 級出售價依序為 15／30／60／120／240／480 金幣。
- 三座開局贈送塔各以 25 金幣估值；舊存檔若記錄為 0，也按等級重置成本補正。
- 確認前顯示實際返還金額。
- 連點或重入不得重複返還金幣。

## 10. 攻擊動畫

- 炮擊：從骰塔拋出有短尾跡的橘色圓球，不使用雷射線。
- 霜凍：射出青色冰晶。
- 毒蝕：拋出綠色毒液泡。
- 連鎖：閃電先由骰塔連到第一個目標，再依命中順序延伸。
- 穿刺：射出紫色箭矢，終點是最後一個穿透目標。
- 刃擊：以骰塔為圓心，朝目標方向快速揮舞旋轉刀刃與半圓弧光；同時展開至完整射程的圓形衝擊環，成功擊退的怪物各自顯示反向風痕與位移光圈。
- 鼓舞：金色星光飛向所有受增益骰塔；爆擊時更亮並顯示強制爆擊待命標記。
- 每次實際攻擊或有效鼓舞脈衝時，來源骰塔在約 0.18 秒內放大至最多 1.10 倍再恢復。
- 波次結束時投射物與命中特效不批次清除，依 TTL 自然淡出。
