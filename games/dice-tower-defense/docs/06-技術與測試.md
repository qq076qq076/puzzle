# 技術與測試

> 文件版本：0.20
> 上層索引：[README.md](./README.md)

本文件定義資料結構、更新順序、保存、效能、錯誤處理與驗收。遊戲數值不在此重複定義；測試應引用各主題文件的正式數值。

## 1. 技術範圍

- 原生 HTML、CSS、JavaScript。
- 單一 Canvas 繪製棋盤、骰塔、敵人與戰鬥特效。
- 不依賴外部 CDN 才能啟動。
- 本機靜態伺服器即可執行。
- 支援最新兩個版本的 Chrome、Safari、Edge 與 Firefox。

目前檔案：

```text

├── style.css

├── 遊戲規格書.md

```

根目錄兩份舊檔名只保留導覽用途，正式規格以 `docs/` 為準。

## 2. 程式責任分區

`script.js` 至少維持以下邏輯區塊：

- `CONFIG`：地圖、骰塔、怪物、波次、平衡參數與素材路徑。
- `createInitialState()`／`resetGame()`：建立乾淨新局。
- 準備階段：倒數、購買、部署、移動、交換、出售與立即合成。
- 戰鬥階段：施工、畫面外進場延遲、狀態、能力、移動、攻擊與死亡。
- `resolveEvents()` 類邏輯：漏怪、擊殺、分裂、金幣、結算與勝負。
- `render()`：只依狀態繪製，不作戰鬥決策。
- `loadProfile()`／`saveProfile()`：本機紀錄與設定。
- 測試／除錯：固定 RNG、指定波次、碰撞盒與事件紀錄。

DOM 文字或 CSS class 不得作為戰鬥邏輯來源。

## 3. 主要狀態

```js
{
  phase: "preparation" | "combat" | "waveResult" | "victory" | "defeat",
  paused: false,
  wave: 1,
  clearedWaves: 0,
  coreHp: 20,
  gold: 120,
  enemyGoldRemainder: 0,
  score: 0,
  towers: [],
  tray: [],
  enemies: [],
  projectiles: [],
  effects: [],
  selectedTowerId: null,
  selectedDieId: null,
  preparationRemaining: 0,
  resultRemaining: 0
}
```

骰塔欄位由[骰子系統](./02-骰子系統.md#1-共通資料)定義；敵人欄位由[怪物系統](./03-怪物系統.md#2-共通資料結構)定義。

## 4. 時間與主循環

- 使用 `requestAnimationFrame`。
- 每幀用 `deltaTime` 更新，單幀最大值限制為 100ms。
- 暫停時不累積邏輯時間。
- 分頁隱藏時自動暫停，恢復時重設 `lastFrameTime`。
- 準備倒數、施工、冷卻、狀態與特效都使用剩餘秒數，不依賴 DOM。
- 同一座骰塔每幀最多執行一次索敵。
- RNG 應可注入種子；正式遊戲可隨機，測試模式必須可重現購買與爆擊。

## 5. 戰鬥更新順序

每個戰鬥邏輯步驟依序：

1. 更新畫面外敵人的進場延遲；剛進場者只使用剩餘 `deltaTime`。
2. 結算在場敵人的毒傷與狀態時間。
3. 若毒傷造成死亡，停止該敵人本幀後續能力。
4. 更新治療、封印、結界、潛地、干擾、再生、狂暴與首領能力。
5. 更新敵人移動並處理漏怪。
6. 更新骰塔施工與法術封印。
7. 更新骰塔攻擊冷卻、索敵與攻擊。
8. 依攻擊分類套用特定抗性、護盾與生命傷害。
9. 處理死亡、金幣、分裂、召喚與波次結束。
10. 更新純視覺特效 TTL。

注意：畫面外敵人不可出現在步驟 2～9 的合法目標集合。

## 6. 同幀與邊界規則

- 敵人死亡與漏怪同幀：死亡優先。
- 護盾由正值降到 0：只建立一個 `shieldBreak`，不得造成停頓。
- 毒傷死亡後：不再施放本幀能力。
- 目標在攻擊前失效：不擲爆擊、不消耗 `forcedCrit`。
- 合成與出售：不可重入；一次放開或一次點擊最多執行一次。
- 金幣不足、目標施工中、等級不符或落點非法：不改變資源與物件。
- 金幣一律為整數，不能出現負數、`NaN` 或 `+0 G`。
- 重新開始：清除當局所有陣列、計時器、拖曳、選取與過場狀態。
- `localStorage` 失敗：遊戲仍可執行，只停用紀錄保存。

## 7. 保存格式

儲存鍵：`puzzle.diceTowerDefense.v1`

```js
{
  version: 1,
  bestScore: 0,
  bestWave: 0,
  settings: {
    sound: true,
    reducedEffects: false,
    vibration: true,
    tutorialCompleted: false,
    hints: true
  }
}
```

- 玩家資料與進行中對局使用不同儲存鍵，避免設定格式升級破壞關卡檢查點。
- 格式錯誤、版本不支援或非物件資料時，回退預設值並覆寫乾淨格式。
- 設定包含音效、降低特效、震動、教學完成與操作提示。

對局檢查點鍵：`puzzle.diceTowerDefense.run.v1`

```js
{
  version: 1,
  savedAt: "ISO timestamp",
  wave: 2,            // 下一個要挑戰的波次
  clearedWaves: 1,
  gold: 170,          // 已包含 35 G 通關獎勵
  coreHp: 20,
  score: 625,
  killGold: 15,
  enemyGoldRemainder: 0,
  bossKills: 0,
  towers: [{ id, type, x, y, tier, totalInvested }],
  diceBag: [{ id, type, tier, totalInvested }]
}
```

- 第 1～29 波守住時立即覆寫檢查點，內容等同下一波準備階段開始狀態。
- 所有施工視為完成；不保存敵人、特效、攻擊冷卻、封印、強制爆擊、選取與拖曳狀態。
- 恢復後使用該波完整準備時間，不追趕關閉頁面期間的時間。
- 勝利、失敗或玩家確認重新開始時刪除檢查點。
- 啟動時只有有效檢查點才顯示「繼續遊戲／重新開始」；格式錯誤、越界、重疊位置或未知骰種資料直接捨棄並開始新局。

## 8. 效能目標

- 桌面以 60 FPS 為目標。
- 中低階手機在 200 個已建立敵人、51 座骰塔、30 個特效同時存在時至少 30 FPS。
- 邏輯與渲染分離，不為每個棋盤格建立獨立 DOM。
- 特效超過 60 個時優先回收最舊的純視覺特效，不影響戰鬥事件。
- 頁面背景節流時不追趕離開期間的模擬。
- Canvas 圖片放大關閉影像平滑。

## 9. 自動化與數值測試

### 9.1 骰塔

- 新骰子永遠是 1 級；只有合成可升至 2～6 級。
- 非霜凍骰大量樣本爆擊率接近 10%／20%／35%／48%／60%／72%。
- 霜凍骰大量樣本接近 2%／3%／4%／6%／8%／10%，6 級不得高於 10%。
- 1 級炮擊普通傷害是 `5.6 × 0.5 = 2.8`，爆擊主傷害是 `4.9`，爆擊範圍是 `3.92`。
- 1 級攻擊間隔使用表列值除以 0.5；2 級除以 0.75；3～6 級不再降頻。
- 鼓舞攻速在等級頻率之後計算，只取相鄰最高值。
- `forcedCrit` 只在下一次有效攻擊消耗，重複鼓舞不累積。
- 連鎖骰使用原穿刺骰的六級攻擊間隔；穿刺骰使用原連鎖骰的六級攻擊間隔。
- 毒蝕骰爆擊命中半徑 1 格內所有合法敵人，不存在彈跳數量上限或 1.5 格跳躍。
- 刃擊骰 1～3 級射程為 2，4～6 級為 3；只有優先目標承受傷害，攻擊成功後射程內所有合法怪物各後退 0.5 格且不低於道路起點。
- 刃擊骰表列間隔為 0.60／0.56／0.52／0.49／0.46／0.43 秒；套用等級頻率後 1 級實際 1.20 秒、2 級約 0.747 秒。
- 同一怪物成功被擊退後 0.75 秒內不接受第二次擊退，但仍正常承受傷害。

### 9.2 特定抗性

- 程式中不存在單一 `allResistance` 或數值型 `waveResistance`。
- 除裝甲蟲外，第 12 波 `resistances` 為空；裝甲蟲只有 `physical: 0.35`。
- 第 13／20／25／30 波只有怪物指定抗性鍵約為 0.0494／0.2104／0.3044／0.424。
- 每種怪物最多兩個抗性鍵，不得同時具有四種。
- 第 20 波分裂蟲承受 100 雷電傷害後約為 78.96；物理與毒素仍為 100。
- 第 20 波迅捷蟲的 2 秒減速約變 1.579 秒，1.2 秒冰凍約變 0.948 秒；直接傷害不降低。
- 第 20 波裝甲蟲承受 100 物理傷害後約為 51.3；連鎖、毒蝕與霜凍直接傷害仍為 100。
- 護盾在對應傷害抗性之後吸收。

### 9.3 怪物能力

- 治療法師在場 12 秒後，從 2.6 格內完工骰塔隨機選 1 座封印 0.7 秒；塔冷卻在封印期間不變。
- 範圍內沒有合法塔時不建立封印；有多座塔時每次仍只能停用一座。
- 施工塔、範圍外塔及畫面外法師不觸發封印效果。
- 再生蟲受傷後至少 2.5 秒才回血；持續毒傷可阻止再生。
- 狂暴蟲半血後永久 1.7 倍移速且只播放一次觸發特效。
- 掠金蟲漏怪扣除 `min(gold, 12)`，不能產生負金幣。
- 結界不疊加超過最大生命 8%，且不保護施法者。
- 潛地期間排除所有新索敵與直接範圍傷害，既有毒傷仍結算。
- 干擾後冷卻不超過完整間隔 1.5 倍。

### 9.4 波次

- 第 1～10 波段落數量為 `round(base × 2.5)`，第 11～30 波為 `round(base × 3.0)`。
- 第 1 波開始後立即存在 15 隻迅捷蟲；第一隻延遲 0，其餘依 1.50 秒累加。
- 第 5／10／15／20／25／30 波生命倍率與[關卡文件](./04-關卡與波次.md#22-生命)一致。
- 第 5 波名目總生命較舊配置至少下降 40%，且第 6 波名目總生命略高於第 5 波。
- 第 8～15／16～25／26～30 波額外生命倍率為 1.85／2.55／4.10，綜合速度與指定抗性壓力後目標難度約為 2×／3×／5×。
- 第 25 波實際為 24 隻巨甲王，不產生迅捷召喚或其他怪物。
- 第 30 波實際為 9 隻裂界巨甲王。
- 第 28～30 波所有生成物均有 12%／16%／20% 最大生命護盾。
- 波次結束需等待畫面外敵人、分裂幼體及召喚物全部離場。

### 9.5 資源與操作

- 連續購買直到金幣不足，待建造區可超出可視高度但不限制數量。
- 金幣不足時購買不扣款、不新增骰子。
- 準備階段部署與合成立即完成；戰鬥階段使用正確施工時間。
- 拖到同類同級塔直接合成；不同塔只在準備階段交換。
- 待建造骰可直接拖到同類同級場上骰塔合成。
- 6 級、施工中或非法目標不消耗材料。
- 同一骰塔再次點擊取消選取；移動超過 10px／14px 才算滑鼠／觸控拖曳。
- 出售返還 `floor(totalInvested × 0.6)`，連點不重複發放。

### 9.6 顯示與結束

- 怪物、底盤、血條與狀態環使用 `9 / 8` 視覺比例，不改變邏輯位置。
- 特定抗性 icon 與棋盤圖例顏色一致，不顯示全抗性灰環。
- 炮擊特效是圓形炮彈；每種骰塔都有來源到目標動畫。
- 刃擊骰攻擊時刀刃以骰塔為圓心朝目標揮舞，不使用飛向怪物的投射物。
- 普通波結束不批次清空特效，不出現整幀卡頓。
- 護盾破裂不暫停敵人、冷卻或戰鬥時間。
- 冰凍中的怪物持續顯示冰色覆層、冰晶與雪花；效果結束後全部消失。
- 首領落地前不可被攻擊或移動；落地播放衝擊波，正常模式有短暫鏡頭震動，降低特效模式不震動。
- 勝利／失敗後重新開始不殘留敵人、投射物、選取或計時器。

## 10. 瀏覽器與互動測試

- 以本機靜態伺服器載入頁面，確認沒有 JavaScript error／warning。
- 桌面測試點擊選取、再次點擊取消、拖曳門檻、交換、合成與出售。
- 戰鬥中測試購買、部署、施工、選取資訊及拖曳合成。
- 驗證抗性圖例在桌面與 320px 寬度都可讀且不遮住按鈕。
- 驗證 Canvas 上怪物抗性 icon、封印、施工、護盾破裂、合成與首領爆炸。
- 分頁隱藏後確認自動暫停，回到頁面不跳秒。

## 11. 平衡驗證

固定 RNG 後，每組至少模擬 100 局：

1. 炮擊＋霜凍：確認第 6～9 波開始有壓力。
2. 霜凍＋毒蝕＋鼓舞：控制可延長停留，但輸出不足仍會失敗。
3. 連鎖＋穿刺＋炮擊：群體強，但首領需要合成與布局。
4. 單一傷害類型：第 13 波後應明顯受到部分怪物特定抗性限制，但仍能傷害其他類型。

每局記錄通關波次、核心、平均金幣、3～6 級塔數量、各級爆擊率、強制爆擊次數與失敗原因。若單一路線通關率超過 70%，優先調整該路線、敵人組成或經濟，不直接提高所有敵人生命。

## 12. 完成定義

- 七種骰塔可購買、部署、施工、攻擊／支援、合成至 6 級並出售。
- 30 波編隊、全部怪物能力、特定抗性與首領規則正常。
- 桌面與手機都能完成主要操作。
- 資源、勝負、保存、暫停與重新開始正確。
- 關鍵動畫與狀態可讀，降低特效模式仍保留能力輪廓。
- 語法檢查、差異檢查、數值斷言及瀏覽器煙霧測試通過。
- 實作若與規格不同，先更新擁有該規則的主題文件及索引版號。

## 13. MVP 外項目

- 線上排行榜與雲端保存。
- 多人合作或對戰。
- 每日任務、成就與劇情。
- 稀有骰子、詞綴與不同購買池。
- 多張地圖與隨機道路。
- 長期養成、帳號與付費內容。
