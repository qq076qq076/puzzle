# Road texture

The road uses the center 16×16 pebble texture from **Top-down Pebble Path** by Vaight:

- Source: https://opengameart.org/content/top-down-pebble-path
- Original file: `pebble_road.png`
- License: Creative Commons Zero (CC0 1.0)
- License URL: https://creativecommons.org/publicdomain/zero/1.0/
- Attribution is not required. Credit: Vaight / OpenGameArt.org

The game scales and repeats the center texture over the S-shaped road drawn by the canvas renderer.
