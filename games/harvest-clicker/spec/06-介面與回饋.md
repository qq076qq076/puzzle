# 介面與回饋規格

## 1. 版面

遊戲區由上下兩個區塊組成：

- 上方 farm-panel：左側商店、右側 Canvas 操作區，兩側等高；商店內容過多時只有商店內部捲動。
- 下方 quickbar-wrap：全寬橫向工具列；手機版項目超出寬度時可左右滑動，不壓縮到難以點擊。

右側只保留 Canvas 與 quickbar-wrap，不再放 farm-topbar、tutorial-card、canvas-toolbar 等解釋性外層。持有金額放在商店標題右側，數字一律以 $ 結尾。「分享農田」固定顯示在 Canvas 右上角，手機收起商店時仍可直接開啟分享面板；唯讀模式不顯示此按鈕。

## 2. 商店

商店頁籤使用圖示代表工具、種子、自動化、肥料與裝飾分類。商品列只顯示圖片、品名與價格；點擊商品開啟介紹面板，顯示用途、數值、解鎖條件與購買按鈕。未解鎖商品列不顯示長文字，使用鎖頭 icon；點擊後才以 popup 顯示解鎖條件。

種子商品縮圖使用成熟花朵或植株圖片，不使用種子袋代替成長樣式。所有價格、收益與購買結果需與靜態資料一致。

## 3. Canvas 操作

- 主要判定單位是土地格子；hover 以格子高亮，植物圖不攔截指標事件。
- 未購土地顯示鎖頭 icon；點擊後 popup 顯示目前累計購地數、下一次價格與可否購買。土地價格依購買數量遞增，與位置無關。
- 種植、肥料、設備與裝飾模式第一次點擊先選取／預覽，第二次確認施作；取消或點擊其他模式會清除預覽。
- 點擊仍在生長的作物，提示剩餘時間，不扣除工具冷卻。
- 桌面版游標顯示當前工具圖片；觸控版保留雙指縮放與拖曳，畫布寬度與螢幕等寬且不留水平 gap。

## 4. 動畫與聲音

除草、購買、種植、施肥、自動化設備各有短動畫與獨立音效。揮動受擊音效與完成收割音效分開。手機低功耗模式降低粒子數、陰影與動畫頻率，避免長時間運作發熱。

## 5. 提示文案

提示需包含動作、目標與結果，例如「選取 3×3 區塊，再次點擊確認種植」、「白花苜蓿還要 12 秒成熟」、「已收割白花苜蓿，獲得 1$」。重要提示在 Canvas 內以可換行框顯示，寬度依螢幕調整。
