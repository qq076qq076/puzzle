# 儲存、離線與驗收規格

## 1. 靜態檔載入

index.html 必須依序載入：

1. game-config.js
2. data/plants.js
3. data/tools.js
4. data/automation.js
5. data/fertilizers.js
6. data/decorations.js
7. game-core.js
8. ../share-utils.js
9. ../firebase-config.js
10. ../firebase-runtime.js
11. script.js

資料檔只負責建立 HarvestStaticConfig 或 HarvestStaticData；遊戲邏輯由 game-core.js 讀取，不在 script.js 重複維護商品數值。

## 2. 儲存格式

localStorage 使用固定 key `puzzle-club-save:harvest-clicker:v4`，資料版本為 4。核心欄位：

- version、savedAt
- coins、lifetimeGold、harvestedCount
- purchasedTools、selectedTool
- ownedSeeds、ownedFertilizers、ownedHarvesters、ownedSprinklers、ownedDecorations
- plots、unlockedPlotIds
- cells：每格的 plantId、plantedAt、readyAt、damage、fertilizer
- trees：樹木根格、footprint、anchor 與狀態
- placedDevices：設備 id、類型、中心格、下一次執行時間
- decorations：裝飾 id、slotType、槽位座標與方向

任何購買、收割、種植、施肥、放置/拆除設備或裝飾、購地都立即存檔；頁面隱藏、離開與定時備份再各保存一次。

## 3. 分享與唯讀快照

- 「分享農場」只對已登入的永久帳號開放，匿名存檔不能公開。
- 點擊「分享農田」後直接建立或更新快照並顯示網址，不再要求第二次確認；網址右側以單一複製 icon 操作，不提供額外的唯讀預覽按鈕。
- 建立分享時，以原子批次寫入私人控制文件 `/users/{uid}/shares/harvest-clicker` 與公開快照 `/publicShares/{shareId}`；公開文件不包含私人存檔路徑或玩家資料。
- 分享網址使用 `#share={shareId}`，分享代碼不進入伺服器路徑、查詢參數或 Referer。代碼需為 20–64 字元，Firestore 禁止列舉公開快照。
- 同一帳號固定重用一組分享網址；「更新分享快照」只覆寫快照內容，不會即時同步後續遊戲操作。
- 「停止分享」會以批次刪除公開快照與私人控制文件，舊網址立即失效。
- 分享快照上限為 900 KiB，保留 Firestore 1 MiB 文件限制所需餘裕。
- 唯讀訪客仍以 Firebase 匿名驗證讀取單一快照，可以拖曳、縮放與點擊查看分享當下的作物狀態；不能購買、收割、播種、施肥、配置設備、拆裝飾、匯入、重設或寫入本機／雲端存檔。
- 唯讀快照不執行離線成長與自動設備補算，確保每次開啟看到相同分享狀態。

## 4. 離線計算

開啟遊戲時以 savedAt 到現在的秒數計算：

1. 先更新作物與樹木的成熟進度，未完成者只更新 readyAt。
2. 再依設備 intervalSeconds 補算自動收割與灑水，依序結算金幣、重生時間與肥料輪數。
3. 設備補算設上限，超出部分以最後一次可結算時間收斂，避免一次開啟產生大量動畫。
4. 完成離線結算後立即存檔，並在 Canvas 顯示離線摘要。

## 5. 驗收清單

- 靜態檔直接以瀏覽器開啟時無 ReferenceError，script.js 能取得所有商品。
- 31 種一般作物與 10 種樹木的價格、血量、成熟時間、收益與 footprint 可由 data/plants.js 讀取。
- 17 種工具、7 種自動收割機、5 種灑水器、10 種肥料與 10 種裝飾的價格和解鎖條件與商店一致。
- 樹木只能以根格收割，整個正方形 footprint 不會被重複計算。
- 裝飾只能吸附在 edge/corner gap grid，不會占用或覆蓋種植格。
- 任一操作後重新整理，金幣、土地、作物、肥料、設備與裝飾狀態皆保留。
- 手機可左右滑動 quickbar、雙指縮放 Canvas，桌面 hover 與工具游標正常。
- 分享者可建立、更新、複製、預覽與撤銷同一個唯讀網址；未登入者會被引導至帳號面板。
- 唯讀網址不會載入本機私人存檔，且所有遊戲修改入口都不會改變快照或觸發存檔。
- game-core.test.mjs、share-utils.test.mjs、node --check 與 git diff --check 全部通過。
