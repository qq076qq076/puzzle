# 儲存、離線與驗收規格

## 1. 靜態檔載入

index.html 必須依序載入：

1. game-config.js
2. data/plants.js
3. data/tools.js
4. data/automation.js
5. data/fertilizers.js
6. data/decorations.js
7. game-core.js
8. ../share-utils.js
9. ../firebase-config.js
10. ../firebase-runtime.js
11. script.js

資料檔只負責建立 HarvestStaticConfig 或 HarvestStaticData；遊戲邏輯由 game-core.js 讀取，不在 script.js 重複維護商品數值。

## 2. 儲存格式

localStorage 使用固定 key `puzzle-club-save:harvest-clicker:v4`，資料版本為 4。核心欄位：

- version、savedAt
- coins、lifetimeGold、harvestedCount
- purchasedTools、selectedTool
- ownedSeeds、ownedFertilizers、ownedHarvesters、ownedSprinklers、ownedDecorations
- plots、unlockedPlotIds
- cells：每格的 plantId、plantedAt、readyAt、damage、fertilizer
- trees：樹木根格、footprint、anchor 與狀態
- placedDevices：設備 `instanceId`、設備 id、類型、中心格、下一次執行時間；移動與 quickbar 排序不得改變 instanceId
- decorations：裝飾 id、slotType、槽位座標與方向

任何購買、收割、種植、施肥、放置/拆除設備或裝飾、購地都立即存檔；頁面隱藏、離開與定時備份再各保存一次。
- 收割、購地、商店購物與自動設備收成等會改變金幣的操作，必須跳過雲端延遲佇列，立即完成本地 checkpoint 與 Firestore 寫入。

## 3. 帳號分享與唯讀農場

- 「分享農場」只對已登入的永久帳號顯示並開放；匿名存檔與唯讀訪客不顯示分享按鈕。
- 點擊「分享農田」後直接建立該帳號固定的唯讀網址，不要求第二次確認；網址右側以單一複製 icon 操作，不提供額外的唯讀預覽按鈕。
- 第一次啟用時，以原子批次寫入私人控制文件 `/users/{uid}/shares/harvest-clicker` 與公開資料 `/publicShares/{shareId}`；公開文件不包含帳號 uid、私人存檔路徑或玩家資料。
- 分享網址使用 `#share={shareId}`，分享代碼不進入伺服器路徑、查詢參數或 Referer。代碼需為 20–64 字元，Firestore 禁止列舉公開資料。
- 同一帳號固定重用同一組分享網址。啟用後，每次成功寫入較新的雲端存檔，都自動鏡像到原公開網址，不需要再次按分享。
- 同一個正式帳號在多台裝置開啟遊戲時，各裝置會監聽 `/users/{uid}/saves/harvest-clicker` 的 Firestore 即時快照。A 裝置完成種植、施肥或配置設備後會立即寫入；B 裝置收到較新的 `serverRevision` 會自動載入、推進離線狀態並重新繪製。若 B 裝置正有尚未上傳的本機操作，先提示玩家選擇載入遠端版本或保留本機版本再上傳，避免靜默覆蓋。
- 公開資料在既有 `data` map 內記錄 `__shareSourceRevision`；只有較新的伺服器版本可以覆寫，避免多分頁或延遲請求讓分享農場倒退。版本欄位不增加公開文件的頂層 schema，確保已部署的舊規則仍可接受自動同步。
- 「停止分享」會以批次刪除公開資料與私人控制文件，舊網址立即失效；再次啟用分享會產生新網址。
- 公開農場資料上限為 900 KiB，保留 Firestore 1 MiB 文件限制所需餘裕。
- 唯讀訪客以 Firebase 匿名驗證讀取單一公開文件，並監聽該帳號後續同步；可以拖曳、縮放與點擊查看目前狀態，但不能購買、收割、播種、施肥、配置設備、拆裝飾、匯入、重設或寫入任何存檔。
- 唯讀端依最新公開存檔的時間在記憶體內推進生長與自動設備，不寫回本機或雲端；因此同一網址每次開啟及保持開啟時都顯示最新可推算狀態。

## 4. 離線計算

開啟遊戲時以 savedAt 到現在的秒數計算：

1. 先更新作物與樹木的成熟進度，未完成者只更新 readyAt。
2. 再依設備 intervalSeconds 補算自動收割與灑水，依序結算金幣、重生時間與肥料輪數。
3. 設備補算設上限，超出部分以最後一次可結算時間收斂，避免一次開啟產生大量動畫。
4. 完成離線結算後立即存檔，並在 Canvas 顯示離線摘要。

## 5. 驗收清單

- 靜態檔直接以瀏覽器開啟時無 ReferenceError，script.js 能取得所有商品。
- 31 種一般作物與 10 種樹木的價格、血量、成熟時間、收益與 footprint 可由 data/plants.js 讀取。
- 17 種工具、7 種自動收割機、5 種灑水器、10 種肥料與 10 種裝飾的價格和解鎖條件與商店一致。
- 樹木只能以根格收割，整個正方形 footprint 不會被重複計算。
- 裝飾只能吸附在 edge/corner gap grid，不會占用或覆蓋種植格。
- 任一操作後重新整理，金幣、土地、作物、肥料、設備與裝飾狀態皆保留。
- 手機可左右滑動 quickbar、雙指縮放 Canvas，桌面 hover 與工具游標正常。
- 正式登入者可建立、複製與撤銷帳號固定的唯讀網址；匿名使用者看不到分享按鈕。
- 分享啟用後，購買、收割、種植等下一次成功雲端存檔會自動更新原網址，較舊版本不能覆蓋較新版本。
- 唯讀網址不會載入本機私人存檔，且所有遊戲修改入口都不會改變公開資料或觸發存檔。
- game-core.test.mjs、share-utils.test.mjs、node --check 與 git diff --check 全部通過。
