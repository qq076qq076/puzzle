# 儲存、離線與驗收規格

## 1. 靜態檔載入

index.html 必須依序載入：

1. game-config.js
2. data/plants.js
3. data/tools.js
4. data/automation.js
5. data/fertilizers.js
6. data/decorations.js
7. game-core.js
8. ../share-utils.js
9. ../firebase-config.js
10. ../firebase-runtime.js
11. script.js

資料檔只負責建立 HarvestStaticConfig 或 HarvestStaticData；遊戲邏輯由 game-core.js 讀取，不在 script.js 重複維護商品數值。

## 2. 儲存格式

localStorage 使用固定 key `puzzle-club-save:harvest-clicker:v4`，資料版本為 4。核心欄位：

- checkpoint envelope：`version`、`createdAt`、`savedAt`、`clientSavedAt`、`serverSavedAt`、`serverRevision`、`revision`、`writerId`
- `schemaVersion`、`lastSimulatedAt`、`accountStartedAt`
- `gold`、`lifetimeGold`、`harvestedCells`、`stats`
- `ownedToolIds`、`equippedToolId`、`inventory`
- `ownedPlots`
- `cells`：每格的 `plantId`、`phase`、`growthProgress`、`currentHp`、樹木根節點／中心格與肥料堆疊
- `harvesters`、`sprinklers`：設備 id、`instanceId`、土地、中心格與收割機 `nextRunAt`
- `settings`：音效與減少動態效果
- `events`：限時活動領取時間與獎勵植物 id
- `decorations`：裝飾 id、slotType、槽位座標與方向

任何購買、收割、種植、施肥、放置/拆除設備或裝飾、購地都立即存檔；頁面隱藏、離開與定時備份再各保存一次。
- 收割、購地、商店購物與自動設備收成等會改變金幣的操作，必須跳過雲端延遲佇列，立即完成本地 checkpoint 與 Firestore 寫入。

帳號權限、Firebase Console 設定、私人／公開文件 schema、固定分享網址、即時 snapshot、版本衝突與唯讀限制集中記錄於 [10-帳號分享與即時同步.md](10-帳號分享與即時同步.md)。本文件只保留本機 checkpoint、雲端寫入時機與驗收項目，避免兩份文件的路徑或規則漂移。

## 3. 離線計算

開啟遊戲時以 savedAt 到現在的秒數計算：

1. 先更新作物與樹木的成熟進度，未完成者只更新 readyAt。
2. 再依設備 intervalSeconds 補算自動收割與灑水，依序結算金幣、重生時間與肥料輪數。
3. 設備補算設上限，超出部分以最後一次可結算時間收斂，避免一次開啟產生大量動畫。
4. 完成離線結算後立即存檔，並在 Canvas 顯示離線摘要。

## 4. 驗收清單

- 靜態檔直接以瀏覽器開啟時無 ReferenceError，script.js 能取得所有商品。
- 21 種一般作物與 10 種樹木（共 31 種）的價格、血量、成熟時間、收益與 footprint 可由 data/plants.js 讀取。
- 17 種工具、7 種自動收割機、5 種灑水器、10 種肥料與 10 種裝飾的價格和解鎖條件與商店一致。
- 樹木只能以根格收割，整個正方形 footprint 不會被重複計算。
- 裝飾只能吸附在 edge/corner gap grid，不會占用或覆蓋種植格。
- 任一操作後重新整理，金幣、土地、作物、肥料、設備與裝飾狀態皆保留。
- 手機可左右滑動 quickbar、雙指縮放 Canvas，桌面 hover 與工具游標正常。
- 正式登入者可建立、複製與撤銷帳號固定的唯讀網址；匿名使用者看不到分享按鈕。
- 分享啟用後，購買、收割、種植等下一次成功雲端存檔會自動更新原網址，較舊版本不能覆蓋較新版本。
- 同一正式帳號的 A／B 裝置會收到最新私人 snapshot；有未同步本機變更時會先提示版本衝突。
- 唯讀網址不會載入本機私人存檔，且所有遊戲修改入口都不會改變公開資料或觸發存檔。
- 限時活動期間首次開啟只領取 1 份緋櫻果樹種子，獎勵進入包包且跨裝置不重複。
- game-core.test.mjs、share-utils.test.mjs、node --check 與 git diff --check 全部通過。
