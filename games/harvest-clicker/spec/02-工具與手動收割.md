# 工具與手動收割規格

## 1. 工具定位

工具是玩家直接操作棋盤時使用的手動收割能力。每把工具由傷害、作用形狀、作用格數與生長倍率組成：

- 傷害：每次點擊對目標植物造成的固定傷害。
- 作用形狀：以玩家點擊格為中心，依形狀取得鄰近土地格。
- 作用格數：該次操作最多處理的土地格數；空格、未解鎖格與不符合樹木占地規則的格子會跳過。
- 生長倍率：收割後同一格雜草或作物下一輪的生長時間倍率，數值越低越快。

植物血量歸零時才會發放收割金幣。只造成傷害時播放揮動與受擊音效，完成收割時另播放完成音效，兩者不可混用。

## 3. 作用範圍與點擊

1. 滑鼠或手指判定以土地格子為主，不以植物圖像邊界為主。
2. 滑過格子時依當前工具形狀預覽範圍；只有已購土地才可高亮。
3. 桌面版遊戲畫面游標使用當前工具圖片，觸控裝置不強制顯示游標。
4. 作用範圍超出棋盤、未購土地或被樹木 footprint 佔用的非根格時，該格不重複計算。
5. 點擊過快時阻止瀏覽器文字選取與拖曳選取，仍保留畫布平移與雙指縮放。

## 4. 樹木工具規則

樹木以根格作為收割目標，工具的傷害只結算一次，但完成時一次清除整個 footprint。若作用範圍只碰到樹冠的非根格，仍導向同一棵樹；若工具範圍無法完整容納 footprint，顯示提示並不執行部分砍伐。

## 5. 動畫與聲音

- 每次有效點擊：工具短暫旋轉或揮動、目標格顯示受擊粒子。
- 植物尚在生長：不造成傷害，顯示剩餘時間提示。
- 植物完成收割：顯示金幣飛出、植物消失，播放獨立的完成音效。
- 動畫使用短生命週期的 DOM/Canvas 物件，避免建立永久節點造成手機發熱。
