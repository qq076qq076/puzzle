# 自動化設備規格

## 1. 設備分類

自動化設備分為自動收割機與自動灑水器。設備購買後先放入背包，再以「設備模式」點擊土地格子配置。第一次點擊只高亮可放置範圍並提示確認，第二次確認才放置；再次點擊 quickbar 中已放置設備，鏡頭會 focus 到設備所在土地。

每個 3×3 土地區塊最多放置一台同類型設備。設備中心點可在區塊內任一已購土地格選擇，作用範圍以中心點向外展開，不限只能放置在 3×3。

## 4. 配置與操作

- 設備模式只允許點擊已購土地；未解鎖土地顯示鎖頭與解鎖條件。
- 作用區域不是 3×3 時，預覽以設備半徑取得棋盤格，閃爍外框包住最外圈有效格，並以中心格標記，不裁切成固定 3×3。
- 已放置設備第一次從 quickbar 點擊會 focus 到所在土地；再次點擊同一個設備會開啟管理 popup，可選擇收回工具列或賣出。每台設備保存固定 `instanceId`，移動位置或 quickbar 排序不會替換設備身份、冷卻時間或作用範圍。
- 收回設備會原樣放回背包；賣出設備返還購買價 60%，兩者都立即存檔，賣出金幣也立即同步雲端。

## 5. 效能與離線

Canvas 只渲染視窗內的車、水霧與高亮，動畫使用 requestAnimationFrame 與低頻粒子上限。背景裝飾不逐幀重繪。重新開啟時先套用離線生長，再依設備間隔補算收割與灑水效果。
