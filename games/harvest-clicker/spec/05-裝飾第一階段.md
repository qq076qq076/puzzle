# 裝飾第一階段規格

## 1. 設計原則

裝飾只放在種植土地格子與格子之間的田埂槽位，不放在土地格子中心，因此不會覆蓋、占用或改變作物與樹木 footprint。第一階段先提供小型田埂、邊緣物件與交叉點標記；池塘、風車、房屋等大型物件延後到第二階段。

目前 data/decorations.js 已完成第一階段商品與靜態設定，Canvas 放置互動列為下一個實作切片；在互動完成前，商店可顯示商品說明但不可誤放到作物格。

## 2. 槽位座標

棋盤仍是 27×27 個種植格。裝飾另使用 gap grid：

- edge 槽位：兩個相鄰種植格之間的水平或垂直縫隙，座標以格子邊界與方向表示。
- corner 槽位：四個種植格交會的交叉點，座標以邊界交點表示。
- 一個裝飾只占一個 edge 或 corner 槽位，不寫入 cells、不改變 plantId、不影響樹木根格。
- 旋轉只影響 edge 的水平/垂直方向，不可把 edge 物件轉成 center 物件。

點擊裝飾模式時，預覽吸附到最近的 edge/corner；若該槽位已有裝飾、超出已購土地邊界或會與樹木 footprint 的渲染層重疊，顯示不可放置提示。

## 4. 放置、收納與存檔

購買後進入裝飾背包。第一次點擊槽位顯示高亮與「放置於格縫／交叉點」提示，第二次確認放置；已放置物件可點擊拆回背包，不退款。裝飾陣列獨立於 cells 儲存，欄位至少包含 id、slotType、x、y、direction、placedAt。

渲染順序固定為土地背景 → 作物/樹木 → 田埂槽位裝飾 → 操作高亮，裝飾不得遮住作物根格。動畫只在放置或拆除時短暫播放。
