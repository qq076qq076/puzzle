# 裝飾第一階段規格

## 1. 設計原則

裝飾只放在種植土地格子與格子之間的田埂槽位，不放在土地格子中心，因此不會覆蓋、占用或改變作物與樹木 footprint。第一階段先提供小型田埂、邊緣物件與交叉點標記；池塘、風車、房屋等大型物件延後到第二階段。

目前 data/decorations.js 已完成第一階段商品與靜態設定，Canvas 已接入 edge/corner 槽位預覽、二次確認、放置、拆除與存檔；裝飾仍不可誤放到作物格。視覺素材統一使用 Kenney 的 CC0 等角農場圖塊，不再以 emoji 或純色幾何圖形代替。

## 2. 槽位座標

棋盤仍是 27×27 個種植格。裝飾另使用 gap grid：

- edge 槽位：兩個相鄰種植格之間的水平或垂直縫隙，座標以格子邊界與方向表示。
- corner 槽位：四個種植格交會的交叉點，座標以邊界交點表示。
- 一個裝飾只占一個 edge 或 corner 槽位，不寫入 cells、不改變 plantId、不影響樹木根格。
- 旋轉只影響 edge 的水平/垂直方向，不可把 edge 物件轉成 center 物件。
- 每個種植格的可見土面縮為 76×38 等角菱形；原 96×48 格距不變，因此相鄰土面之間保留約 10px 的可見田埂帶，專門承接裝飾。

點擊裝飾模式時，預覽吸附到最近的 edge/corner；若該槽位已有裝飾、超出已購土地邊界或會與樹木 footprint 的渲染層重疊，顯示不可放置提示。

## 4. 放置、收納與存檔

購買後進入裝飾背包。第一次點擊槽位顯示高亮與「放置於格縫／交叉點」提示，第二次確認放置；點擊已放置物件可確認拆回背包，不退款。裝飾陣列獨立於 cells 儲存，欄位包含 id、slotType、row、col、direction、placedAt。

渲染順序為土地背景 → 地面型裝飾 → 依接地腳點深度混合排序的作物、樹木與立體裝飾 → 生長／血量資訊 → 操作高亮。位於作物後方的籬笆會被作物遮住，位於作物前方的籬笆會正確遮住作物下段；進度條與操作提示始終保留在資訊層。動畫只在放置或拆除時短暫播放。
