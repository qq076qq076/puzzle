# 00｜核心循環與土地

## 1. 核心循環

1. 等待作物成熟。
2. 使用手動工具點擊造成傷害。
3. HP 歸零後獲得金幣，植物進入下一輪生長。
4. 用金幣購買更高階工具、種子、土地、設備與肥料。
5. 逐步把手動工作交給自動化設備。
6. 關閉遊戲後，下一次開啟依時間差補算生長與設備脈衝。

成熟植物才能受到傷害。工具的多格範圍會對每個有效目標格造成完整傷害，不依距離遞減。

## 2. 棋盤與土地

| 項目 | 設定 |
|---|---|
| 完整棋盤 | 27×27，共 729 格 |
| 土地網格 | 9×9 個地塊 |
| 每塊土地 | 3×3 格 |
| 初始土地 | 中央 3×3 個地塊，共 9×9、81 格 |
| 可購土地 | 其餘 72 塊，可任意位置購買 |

土地不需要相鄰解鎖。所有未購土地使用同一個購地階段價格，價格只依已擁有土地數量增加，與位置無關。

## 3. 初始狀態

- 金幣：0$。
- 初始作物：81 格成熟雜草。
- 雜草：HP 1、收割獲得 1$、生長時間 30 秒。
- 初始工具：小刀，傷害 1、單格作用。
- 初始設備：沒有收割機、灑水器或肥料。
- 初始設定：音效開啟、減少動態效果關閉。

## 4. 土地價格

- 初始 9 塊土地免費。
- 第 10 塊價格為 1,200$。
- 價格公式：

  roundLandPrice(1,200 × 1.45 ^ 額外購地數量)

- 前段價格：1,200$、1,700$、2,500$、3,700$、5,300$、7,700$、11,000$、16,000$、23,000$、34,000$、49,000$。
- 第 81 塊土地價格為 340T$。
- 新購土地的 9 格從雜草生長中開始，30 秒後成熟。

土地數量門檻採寬鬆曲線：高階作物、工具與肥料最早在 6～45 塊土地間逐步開放；土地位置不影響門檻，仍只依累計擁有數量判定。

點擊未購土地會顯示鎖頭、當前統一價格與解鎖條件。金幣足夠時，必須再經過一次購買確認。

## 5. 視角與世界

- Canvas 使用等角 2.5D 投影。
- 農田外側固定配置山、水、樹叢、野花與農舍。
- 山水與房屋位於農田旁，不疊在農田底下。
- 背景、土地與裝飾跟隨同一個相機縮放與拖曳。
- 桌面支援滑鼠拖曳與滾輪縮放。
- 手機支援單指拖曳與兩指縮放。
- 相機不允許把已購農田完全拖出畫面。
- Hover 以土地菱形格判定，不以植物透明像素判定。
