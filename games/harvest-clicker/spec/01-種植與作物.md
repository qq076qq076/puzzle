# 01｜種植、作物與樹木

## 1. 播種規則

一般作物使用一份種子播滿選定的 3×3 土地，共 9 格；同一塊土地重新播種時會覆蓋原作物、成長進度與肥料。

樹木使用一份種子只種植一棵。樹木必須選擇中心格，完整正方形占地都位於已購土地內才可確認。樹木占地可跨越 3×3 地塊，但不可碰到未購土地或棋盤邊界。

播種流程：

1. 從商店購買種子。
2. 種子進入 Quickbar。
3. 選擇一般作物後點擊 3×3 地塊；選擇樹木後點擊中心格。
4. Canvas 顯示實際覆蓋範圍與是否會覆蓋既有作物。
5. 確認後扣除一份種子並開始生長。

## 4. 樹木內部資料

樹木資料必須包含：

- type：tree
- footprint：奇數正方形邊長
- plantRootIndex：占地左上角根節點
- plantAnchorIndex：玩家選取的中心格

Canvas 只繪製根節點，收割、肥料、灑水與自動設備則以根節點代表整棵樹。

## 5. 生長與覆蓋

- 成長進度使用 0 到 1 保存。
- 作物成熟時設定 currentHp 為資料表 HP。
- 收割後作物回到 growing，不需要重買種子。
- 一般作物覆蓋會清除原本 3×3 的植物與肥料。
- 樹木覆蓋會清除與新正方形占地重疊的既有植物與肥料。
- 舊版無樹木根節點的 3×3 樹木會在載入時遷移成單棵樹。
