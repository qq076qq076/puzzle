# 08｜農夫角色與農場氣氛

## 1. 角色素材

- 角色使用 `assets/farmer-green-cap.png`，為 16×18 像素、3×4 方向行走圖。
- 素材來源：[OpenGameArt — Green Cap Character 16x18](https://opengameart.org/content/green-cap-character-16x18)。
- 授權為 CC0；角色在 Canvas 依等角座標縮放，腳底接觸點對齊土地表面。

## 2. 移動規則

- 農夫只在已購土地的格子中心之間隨機選點移動。
- 抵達目標後停留約 1～3 秒，再選擇下一個目標。
- 移動與停留不修改存檔，不影響作物、生長、設備或金幣，是純視覺氣氛角色。
- 角色深度依腳底接觸點排序，因此會被前方作物或裝飾遮住，也會遮住後方物件。

## 3. 動作狀態

| 動作 | 視覺表現 | 觸發比例 |
|---|---|---:|
| 行走 | 3 格方向行走循環 | 持續 |
| 鋤田 | 揮動鋤頭、地面出現短暫耕痕 | 28% |
| 澆水 | 手持水壺、低密度水滴落下 | 25% |
| 擦汗休息 | 擦額頭、汗滴閃動 | 25% |
| 唱歌 | 頭頂顯示音符泡泡 | 14% |
| 張望 | 短暫停留觀察農田 | 8% |

動作特效使用簡單 Canvas 線條、圓形與文字，不建立高頻粒子；手機低功耗模式會降低更新頻率與水滴數量，減少發熱。

## 4. 與遊戲操作的關係

- 農夫不攔截滑鼠、觸控或土地格子的 hover 判定。
- 農夫不會覆蓋作物進度條、血量條、設備範圍或操作提示。
- 唯讀分享農場也會顯示農夫，但訪客不會改變農夫行為或遊戲狀態。

## 5. 農場外圍景觀

- 景觀只放在已購農田外側，不疊加在土地背景底下，也不攔截土地格子的 hover／點擊。
- Canvas 會依相機一起縮放山丘、水面、樹叢、野花與農舍，讓景觀與農田保持同一張世界畫布的比例。
- 景觀採固定低頻繪製；縮放、拖曳或擴張土地時維持在農田旁，不會跟著某一塊土地漂移到作物上方。
