# 格田收割記（Harvest Clicker）遊戲規格書

> 文件版本：3.0  
> 遊戲類型：單人點擊／放置農場  
> 目標平台：桌面與行動版現代瀏覽器  
> 核心操作：點擊收割、3×3 播種、擴張土地、配置範圍自動化

## 1. 遊戲概念

《格田收割記》提取點擊成長遊戲「立即操作、獲得資源、購買強化、逐步自動化」的循環，改造成 2.5D 棋盤農場。玩家從中央 9×9、共 81 格成熟雜草開始，使用小刀逐格收割；金幣可購買農具、種子、土地、收割機、灑水器與一次性肥料。

植物與自動設備在玩家離線時持續計算。畫面只保留左側商店，以及右側上下兩區：全寬 Canvas 農場與全寬 Quickbar。

## 2. 核心循環

```text
植物成熟 → 點擊造成傷害 → HP 歸零並發放金幣
     ↑                                  ↓
離線生長／灌溉 ← 購買種子、土地、工具與自動設備
```

- 成熟植物才能受到傷害；HP 歸零後立即換成金幣並重新生長同種植物。
- 一般種子包一次覆蓋一塊完整 3×3 土地；樹木種子一次只種植一棵，依樹木規格占用完整正方形格數，收割後皆不需再次購買種子。
- 工具範圍超出棋盤或未購土地時，自動裁切無效格。
- 所有金額在畫面上統一顯示為「數字＋`$`」。

## 3. 初始狀態與農田

- 金幣：0$。
- 完整棋盤：27×27，共 729 格。
- 土地：9×9 個地塊，每個地塊為 3×3，共 81 塊土地。
- 初始土地：中央 3×3 個地塊，即 9×9、共 81 格。
- 初始作物：所有初始格皆為成熟雜草，HP 1、收割 1$、再生 30 秒。
- 初始工具：小刀，傷害 1、範圍 1 格。
- 可購土地：其餘 72 塊皆可自由選擇位置，無相鄰或環狀解鎖限制。

### 3.1 土地價格

- 第 1–9 塊為初始免費土地。
- 第 10 塊價格為 1,200$。
- 後續價格公式：`roundLandPrice(1,200 × 1.45 ^ 額外購地數量)`，取兩位有效數量級；價格只依已擁有土地數量計算，與所選位置無關。
- 前段價格依序為 1,200$、1,700$、2,500$、3,700$、5,300$、7,700$、11,000$、16,000$、23,000$、34,000$、49,000$。
- 第 81 塊價格為 340T$。
- 新購土地的九格從雜草生長中開始，30 秒後成熟。
- 所有未購土地在同一購地階段顯示相同狀態與價格；金幣足夠時顯示可購買符號，否則顯示鎖頭。玩家可點擊任意位置查看當前統一價格，可購買時仍需二次確認。

### 3.2 視角與環境

- Canvas 以等角投影繪製完整土壤塊與細格線；植物底部貼住土面並帶接觸陰影。
- 植物生長條與受傷 HP 條顯示在植物上方。
- 完整 27×27 農田的左右外側配置遠山、水池、樹叢、野花與農舍；山水不可墊在農田下方，所有景觀都位於固定世界座標並和土地一起縮放及拖曳。
- Canvas 不疊加固定於螢幕的第二層背景或紋理，避免縮放時出現兩張圖分離的感覺。
- 預設視角只框入已購土地；可用滑鼠拖曳、滾輪、單指拖曳及兩指縮放。
- 相機受到已購農田範圍約束，不能把農田完全拖出畫面。
- 桌面滑鼠在 Canvas 上隱藏系統游標，改顯示目前裝備的農具圖片；Hover 判定以土地菱形格為準。

## 9. 商店與操作介面

```text
┌──────────────┬────────────────────────────────────┐
│ 商店／金幣   │        全寬 27×27 Canvas 農場      │
│ 圖示頁籤     │                                    │
│ 商品名稱 價格├────────────────────────────────────┤
│              │          全寬 Quickbar             │
└──────────────┴────────────────────────────────────┘
```

- `farm-panel` 本身無 Padding，直接分成上方 Canvas 與下方 Quickbar 兩區。
- Canvas 與 `quickbar-wrap` 均使用農場欄完整寬度。
- 桌面版商店欄與右側農場欄固定等高；商店標頭、頁籤與頁尾固定，商品清單在剩餘高度內獨立垂直捲動。
- 持有金幣顯示在「農場商店」右側，不顯示自動存檔狀態，將垂直空間保留給商品。
- 左側商店只有農具、種子、自動化、肥料四個圖示頁籤，不顯示土地商品。
- 商品卡放大素材、品名與價格；詳細用途、數值與解鎖條件放在點擊後的 Popup，尚未解鎖時也必須解說用途。
- 種子商品圖使用成熟作物圖片；所有農具與設備使用實際工具圖片。
- Quickbar 顯示已購工具、種子、肥料、未配置設備及已配置設備；點擊工具裝備，點擊物品後再點土地使用。點擊已配置的收割機或灑水器時，鏡頭平滑移到設備所在土地並以金色外框聚焦，同時保留將設備移往其他土地的操作。
- 手機版遊戲區須貼齊螢幕左右邊緣，不保留外側 Gap 或圓角；Quickbar 維持單列並依螢幕寬度縮放項目，內容超出時可直接左右觸控滑動。
- 手機版 Canvas 內的土地資訊與施作確認提示框，以左右安全邊距自動決定寬度；窄螢幕或橫向畫面內容過高時，可在提示框內垂直捲動。
- 選擇一般種子或肥料後，第一次點擊已購土地只會選定並高亮整塊 3×3 土地；選擇樹木種子、收割機或灑水器後，第一次點擊已購土地內任一格會把該格設為中心，並高亮樹木實際占地或設備的 1×1／3×3／5×5／7×7／9×9 作用範圍。兩者都會顯示施作內容、覆蓋警告與確認按鈕；確認後才消耗物品、執行施作並存檔，取消或重新選擇土地不消耗物品。
- 遊戲區停用瀏覽器文字框選，快速連點、拖曳或雙擊不應反白頁面文字與圖片。

### 9.1 操作回饋

- 每次在已購土地上執行收割點擊，農具游標會以握柄為軸揮動，所有命中格同時顯示短暫的弧形割痕與葉片飛散效果。
- 成功砍除植物時增加第二道刀光、依作物顏色飛散的碎葉與土塵；只造成傷害時使用較輕量的刀光。
- 範圍農具的揮動效果覆蓋實際命中格；超出棋盤或未購土地的格子不顯示效果。
- 種植一般作物時九格依序顯示落種、土壤擴散與嫩芽抽高動畫；種植樹木時依其占地顯示精簡版落種與土壤擴散動畫。
- 配置收割機時顯示齒輪落地衝擊；配置完成後，土地中央保留設備站圖示，另有一台收割車沿該 3×3 地塊外圈持續巡迴，林業設備巡迴時帶有木料標記與木屑。
- 配置灑水器時顯示水滴與擴散水波；配置完成後持續顯示旋轉水柱、落點與地面水波。
- 施肥確認後顯示專屬鋪肥動畫，並在肥效存在期間顯示施肥機逐列往返與撒布顆粒；啟用「減少動態效果」時，車輛停在固定位置但設備狀態仍清楚可見。
- 成熟植物受到傷害但 HP 尚未歸零時播放低沉的傷害聲；HP 歸零完成割除時播放獨立的葉片切斷與明亮完成音；兩者不可共用同一段提示音。
- 點擊尚未成熟的植物時，提示該作物名稱與距離成熟的預估剩餘時間；時間須包含農具再生倍率、肥料及灑水器的加速效果。
- 購買農具、種子、設備、肥料或土地成功後，播放三音階購買提示音；播種、施肥及配置設備使用較輕的放置音。
- 瀏覽器音訊在首次有效點擊時啟用；關閉「遊戲音效」後不建立或播放新聲音。
- 啟用「減少動態效果」時，揮動時間縮短且只保留中心格割痕。
- 行動裝置自動啟用低功耗 Canvas：繪製頻率上限約 24 FPS、像素倍率上限 1.25、停用植物浮動與高成本陰影，並減少水滴、木屑與肥粒數量；不影響作物成長、收割與離線結算。

## 10. 儲存與離線結算

- 儲存位置：瀏覽器 `localStorage`。
- Schema：v4；儲存鍵為 `puzzle-club-save:harvest-clicker:v4`。
- v3 的 15×15 存檔會自動遷移到 27×27，保留金幣、統計、作物、工具與已配置設備，並補足新的中央 9×9 初始土地。
- 舊版曾以 3×3 種下的樹木會在載入時合併為單棵樹，保留其作物狀態並套用新的正方形占地規則，避免重複收成。
- 已配置設備新增 `centerIndex` 保存實際作用中心；舊有未記錄中心格的設備會相容地使用原 3×3 地塊中心。
- 每 10 秒自動存檔；購買、收割、播種、施肥、裝備工具、配置設備與購買土地後立即存檔。
- 分頁隱藏、關閉、匯出與匯入時也會先結算並儲存。
- 重開遊戲時，以 `現在時間－lastSimulatedAt` 推進成長與所有收割機脈衝；沒有收割機的成熟植物不會自動產生金幣。
